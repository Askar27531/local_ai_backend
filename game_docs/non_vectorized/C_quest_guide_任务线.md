# 09 任务线设计

> 本文件用于任务系统、开发规划和“我该做什么”类提示逻辑，不建议进入 NPC 普通 RAG 检索。NPC 普通回答应使用世界知识；任务提示应结合 `current_quest`、`inventory`、`known_clues`、`visited_locations` 和本文件的任务状态。

## 任务设计总原则

任务线要让玩家通过“地点探索 -> 道具组合 -> 回访验证 -> NPC 验证 -> 新地点解锁”的循环推进，而不是由 NPC 一次性讲出答案。NPC 不是答案入口，而是证据的社会解释者、情绪反馈者和低风险方向提示者。

每个任务必须遵守以下规则：

1. 早期只回答现象，不回答原理。
2. 中期让玩家拿到证据，并通过地点回访或道具组合先产生可观察反馈；NPC 只能验证、质疑或补充个人视角。
3. 后期才确认 Project ECHO、Subject 07、保护仓、父母权限和主共振核心。
4. 普通 NPC 只给自己能知道的任务提示，不能因为玩家问“下一步做什么”就越过知识边界。
5. 如果玩家跳过线索强行追问真相，NPC 应要求玩家先找到对应物品、地点或证据。
6. 每个关键道具至少关联一个可回访地点、一个组合用途和一个可验证 NPC。
7. 关键推进不应只依赖“询问某 NPC”。如果 NPC 死守沉默，玩家仍应能通过环境痕迹、道具组合或终端低权限反馈推进。
8. NPC 给出的“下一步”应优先指向地点或道具动作，例如“回灯室看光斑”“把三块拓片拼全”“带样本回草药屋”，而不是直接说明结论。

## 探索推进标准循环

每条主线建议使用以下循环：

1. 误读：玩家从传闻、NPC 态度或第一眼环境中获得一个不完整理解。
2. 现场调查：玩家在地点中发现可交互物、痕迹或异常反馈。
3. 道具组合：玩家用已有道具检查新地点，或把新道具带回旧地点触发变化。
4. NPC 验证：NPC 只确认表面意义、个人经验或风险，不讲完整真相。
5. 村庄反馈：公告板、闲聊、NPC 摆设或日常事件发生轻微变化。
6. 新入口：玩家获得下一地点、下一道具或下一次回访目标。

示例：井边传闻不是直接问 Nia 得答案，而是听到孩子传话失控，调查井边贝壳，带贝壳风铃回访井口，再让 Lira/Mara 验证“这不是普通玩笑”。

示例：灯塔下层不是问 Orin 开门，而是取得灯塔日志、灯塔齿轮缺片、三石碑拓片和门禁残角，让灯室光斑与外门反馈共同迫使 Orin 承认玩家已接近旧门。

## 主线任务 1：醒在陌生海岸

建议解锁等级：1。

触发条件：游戏开始。玩家在漂流海滩醒来，失去记忆。

主要地点：`漂流海滩：开场醒来地点`、`漂流海滩：早期可调查线索`、`海上边界：无法离开的外缘`。

关键道具：`破损金属铭牌：早期可见信息`、`失效指南针：早期可见信息`、`湿透的航海笔记残页`。

玩家目标：

- 查看周围残骸，确认自己不是在普通海岸。
- 拾取破损金属铭牌、失效指南针和航海残页。
- 尝试沿海岸或出海方向离开，触发归潮边界体验。
- 前往静潮村寻找活人和解释。

关键线索：

- `broken_badge`
- `failed_compass`
- `wet_navigation_page`
- `sea_fog_loop`
- `cannot_leave_island`

NPC 提示逻辑：本任务开始时不依赖 NPC。玩家抵达村庄后，Karo 可解释海雾危险，Lira 可检查失忆症状，Nia 可提供灯塔蓝光传闻。

禁止提前透露：Subject 07 真实身份、Project ECHO 性质、保护仓、低温休眠、父母身份。

推荐提示：

- 如果玩家卡在海滩：提示调查潮线附近的金属残片、湿纸页和指南针。
- 如果玩家反复尝试离岛：触发海雾、罗盘失效和回到原点体验。
- 如果玩家问“我是谁”：当前只能回答“你身上有一块奇怪铭牌，但没人能立刻解释它”。

## 主线任务 2：静潮村与第一轮问询

建议解锁等级：1。

触发条件：玩家发现无法离岛后进入静潮村。

主要地点：`静潮村：村庄整体布局`、`静潮村：公告板、水井和发电机`、`村口码头：Karo 的活动区域`、`草药屋：Lira 的诊疗空间`、`长老屋：Mara 的禁忌和祭歌`。

关键道具：`破损金属铭牌：早期可见信息`、`失效指南针：早期可见信息`、`回声病病历：早期病症记录`、`Mara 的贝壳护符`。

玩家目标：

- 阅读公告板的雾季提醒、井边禁令和灯塔蓝光夜告示。
- 调查水井、发电机棚、草药屋病历和村口码头的表层痕迹。
- 将铭牌、指南针或航海残页分别拿给 Karo、Lira、Nia 或 Mara 验证表面反应。
- 通过 NPC 反应确认哪些地点值得回访，而不是要求他们解释真相。

关键线索：

- `karo_failed_escape`
- `echo_sickness_symptoms`
- `lighthouse_blue_light_rumor`
- `well_echo_rumor`
- `blue_vein_taboo_surface`

NPC 提示逻辑：

- Karo 只会说海雾、罗盘和码头旧船。
- Lira 只会说回声病症状和记录梦境。
- Nia 只会说孩子视角的灯塔、井边和蓝色石头。
- Mara 只会说禁忌，不会讲科学解释。

禁止提前透露：地下设施、Project ECHO 完整含义、灯塔控制节点、玩家身份。

任务完成条件：玩家至少获得一个码头方向线索、一个草药屋病症线索、一个井边或灯塔传闻，并在村庄环境中看见对应日常规则。

## 主线任务 3：旧码头与离岛失败证据

建议解锁等级：2。

触发条件：玩家从 Karo 或航海残页得知旧码头存在离岛失败记录。

主要地点：`村口码头：Karo 的活动区域`、`村口码头：离岛失败证据`、`海上边界：无法离开的外缘`。

关键道具：`Karo 的受潮航海本`、`磁化船钉`、`旧无线电录音`、`湿透的航海笔记残页`。

玩家目标：

- 调查旧船内侧的航行刻痕。
- 找到磁化船钉或旧无线电录音。
- 将航海残页、船舱刻痕和磁化船钉进行对照。
- 回访码头观察 Karo 是否收起工具、盖住船舱或拆下无线电电池。
- 将码头证据拿给 Venn 或 Lira 验证“重复规律”和“身体反应”，而不是让他们解释原理。

关键线索：

- `failed_escape_repeated`
- `magnetized_boat_nails`
- `radio_noise_repeat`
- `karo_navigation_book`
- `fog_not_weather`

NPC 提示逻辑：

- Karo 可透露离岛失败规律，但不解释装置。
- Venn 可说归潮像边界折回。
- Lira 可把 Karo 的头痛和长期接触海雾联系起来。

禁止提前透露：地下水晶场完整原理、灯塔是地表控制节点、Project ECHO。

任务完成条件：玩家通过船舱刻痕、物理痕迹和至少一次 NPC 验证，确认归潮不是偶发迷航，而是有重复规律的异常现象。

## 主线任务 4：草药屋、回声病与蓝色碎片

建议解锁等级：2 到 3。

触发条件：玩家出现头痛、幻听、梦境重复，或获得蓝色水晶碎片、Nia 的蓝色小石头、Lira 的样本瓶。

主要地点：`草药屋：Lira 的诊疗空间`、`草药屋：旧病历和样本柜`、`静潮村：公告板、水井和发电机`。

关键道具：`回声病病历：早期病症记录`、`Lira 的样本瓶`、`Nia 的蓝色小石头`、`Lira 继承的旧病历夹`。

玩家目标：

- 让 Lira 检查玩家症状。
- 观察蓝色碎片是否加重头痛或梦境。
- 调查井边回声和 Nia 藏起的小石头。
- 使用贝壳护符、贝壳风铃或井边潮湿纸卷回访水井，确认“喊名”和“贝壳声”的差异。
- 将蓝色小石头、样本瓶和病历日期交给 Lira 验证症状关联。
- 解锁 Lira 继承的旧病历中的大震夜伤者记录，但旧病历只作为证据，不作为答案。

关键线索：

- `echo_sickness_not_normal`
- `blue_fragment_causes_headache`
- `nia_blue_stone`
- `old_medical_records_after_quake`
- `underground_knocking_rumor`

NPC 提示逻辑：

- Lira 可从病症和样本角度解释，但不能说人体实验。
- Nia 可交出蓝色小石头。
- Mara 可警告不要把蓝脉石带回家。
- Venn 可把病症和记忆残留联系起来。

禁止提前透露：保护仓、Subject 07、父母权限、具体人体实验。

任务完成条件：玩家通过井边回访、样本观察和病历验证，理解蓝色碎片、回声病、雾林和大震夜之间存在关联。

## 主线任务 5：蓝光与守塔人

建议解锁等级：2 到 3。

触发条件：玩家掌握灯塔蓝光传闻、码头异常或灯塔看守日志线索。

主要地点：`废弃灯塔：地表部分`、`废弃灯塔：Orin 的守门区域`。

关键道具：`灯塔看守日志`、`破损金属铭牌：早期可见信息`、`失效指南针：早期可见信息`。

玩家目标：

- 前往废弃灯塔地表调查破损灯室、旧日志和异常电缆。
- 与 Orin 对话，试探灯塔蓝光和旧钥匙。
- 获取灯塔齿轮缺片或灯塔看守日志可读页。
- 回访灯室，尝试用日志日期、齿轮缺片和指南针/拓片线索观察灯镜光斑。
- 出示已获得的地点证据，让 Orin 承认玩家已经看见了“门前的痕迹”。

关键线索：

- `lighthouse_not_normal`
- `orin_guarding_more_than_lighthouse`
- `lighthouse_log_blue_light`
- `old_key_exists`
- `forest_steles_needed`

NPC 提示逻辑：

- Orin 不会因为玩家直接问 Project ECHO 就说出真相。
- Karo 可说灯塔亮时海更危险。
- Venn 可说灯塔可能是边界的一部分。
- Mara 可把灯塔称为外来者插进岛上的铁针。

禁止提前透露：灯塔完整控制节点、地下设施结构、玩家身份。

任务完成条件：玩家不靠 Orin 口头说明，而是通过灯室、日志和光斑反馈获得去雾林寻找石碑和进一步证明的目标。

## 主线任务 6：雾林石碑与蓝脉边界

建议解锁等级：3。

触发条件：Orin、Mara、Venn 或传闻指向雾林三块石碑。

主要地点：`雾林：边界与异常植物`、`雾林：三块石碑与旧轨道`、`雾林：地下通风口和异常回声`、`长老屋：Mara 的禁忌和祭歌`。

关键道具：`雾林风铃碎片`、`雾林石碑拓片`、`Mara 的祭歌木片`、`地下通风口金属铭片`、`蓝色水晶碎片：早期可见信息`。

玩家目标：

- 找到三块石碑并获得拓片。
- 观察蓝色苔藓、风铃重复声和指南针异常。
- 发现旧轨道或地下通风口金属铭片。
- 将三块拓片与 Mara 的祭歌木片顺序、雾林风铃重复次数和指南针停顿方向对照。
- 回访长老屋或灯塔，用闭合环图案验证它不是单块石碑的孤立符号。
- 将拓片拿给 Mara、Orin 或 Venn 验证其文化含义、门禁关系或边界猜测。

关键线索：

- `three_steles_ring_symbol`
- `blue_vein_boundary`
- `forest_compass_abnormal`
- `underground_air_vent`
- `steles_lighthouse_connection`

NPC 提示逻辑：

- Mara 解释石碑是边界，不是装饰。
- Orin 承认石碑图案与灯塔下层入口有关。
- Venn 认为闭合环形符号与归潮边界有关。
- Lira 可注意雾林植物和头痛症状。

禁止提前透露：主共振核心、关闭流程、Subject 07 完整身份。

任务完成条件：玩家获得进入灯塔下层的必要线索组合：闭合拓片、灯塔日志/光斑证据，以及 Orin 无法否认的门前痕迹。

## 主线任务 7：旧钥匙与灯塔下层

建议解锁等级：4。

触发条件：玩家获得雾林石碑拓片、灯塔看守日志或足够证据说服 Orin。

主要地点：`废弃灯塔：隐藏下层入口`、`地下实验设施：入口通道`。

关键道具：`灯塔旧钥匙`、`Orin 的旧门禁牌`、`Orin 的烧焦钥匙环`、`地下通风口金属铭片`。

玩家目标：

- 找到 Orin 不能否认的门禁证据，例如旧门禁牌残角、烧焦钥匙环或灯塔光斑后的检修盖线索。
- 组合灯塔旧钥匙、雾林闭环拓片和旧门禁牌残角，完成外层门禁三件套。
- 让 Orin 验证玩家已具备开门证据，但不要求他说出门后全貌。
- 发现蓝光导管、旧控制台、Project ECHO 残缺标识和设施入口通道。

关键线索：

- `lighthouse_lower_entry`
- `external_group_mark`
- `project_echo_first_confirmed`
- `orin_guilt`
- `path_to_underground`

NPC 提示逻辑：

- Orin 可承认外来者设施存在，但仍不讲全貌。
- Venn 可对门禁牌和标识产生熟悉感。
- Lab Terminal 若尚未正式访问，只能离线或权限不足。

禁止提前透露：父母身份、保护仓弹射、完整实验事故、关闭流程。

任务完成条件：玩家通过三件套开门反馈确认灯塔下方存在旧设施，并解锁地下设施入口。

## 主线任务 8：地下设施前段与晶体样本

建议解锁等级：4。

触发条件：玩家进入地下设施入口通道。

主要地点：`地下实验设施：入口通道`、`地下实验设施：晶体样本室`、`海上边界：后期边界理解`。

关键道具：`蓝色水晶碎片：后期解释`、`Orin 的旧门禁牌`、`Venn 涂黑的研究页`、`失效指南针：后期解释`。

玩家目标：

- 调查入口通道和样本室。
- 将蓝色碎片与地下蓝脉矿脉联系起来。
- 收集入口终端索引针、主走廊纸带片或频率音叉组。
- 恢复入口终端低权限索引，读取有限分区状态，而不是直接查询真相。
- 使用蓝色透镜或频率音叉回访晶体样本室，观察空托架裂纹、标签底色和样本柜频率锁。
- 首次通过终端残缺字段、样本室反馈或标识确认 Project ECHO 是设施相关名词。
- 让 Venn 或 Orin 对旧资料产生反应。

关键线索：

- `project_echo_facility_confirmed`
- `crystal_samples_under_island`
- `resonance_field_hint`
- `lighthouse_surface_node_hint`

NPC 提示逻辑：

- Lab Terminal 可给低权限片段。
- Venn 可提出边界理论。
- Orin 可承认自己见过这些设施痕迹。

禁止提前透露：Subject 07 完整确认、父母权限、核心关闭流程。

任务完成条件：玩家通过终端索引恢复、样本室二次观察和 NPC 验证，理解归潮与地下蓝脉、灯塔、边界场存在关系。

## 主线任务 9：人体观测区与保护仓线索

建议解锁等级：5。

触发条件：玩家进入地下设施深处，或获得保护仓外壳碎片、实验日志碎片等后期道具。

主要地点：`地下实验设施：人体观测区`、`地下实验设施：低温休眠舱区`、`漂流海滩：后期保护仓残迹`。

关键道具：`保护仓外壳碎片`、`Subject 07 保护仓接口片`、`实验日志碎片`、`安全弹射记录残页`。

玩家目标：

- 调查人体观测区，确认 Project ECHO 涉及人体观测或实验。
- 在低温休眠舱区找到保护仓接口和弹射记录。
- 将海滩保护仓残迹与地下设施记录对应起来。
- 回访漂流海滩潮沟，用保护仓外壳碎片、蓝色透镜或终端片段验证开场残骸不是普通海难。
- 通过 Lab Terminal、接口片和安全弹射记录交叉验证 Subject 07 相关片段；Venn 只能提供不稳定反应。

关键线索：

- `human_observation_confirmed`
- `cryo_protection_area`
- `emergency_ejection_record`
- `subject_07_near_confirmed`
- `beach_not_shipwreck`

NPC 提示逻辑：

- Lab Terminal 可显示残缺记录。
- Venn 可产生保护仓残影，但应保持不确定。
- Lira 可从医学角度意识到玩家状态不是普通海难。
- Orin 可承认自己早就怕玩家走到这里。

禁止提前透露：父母完整动机和最终关闭流程，直到玩家获得父母权限或录音带。

任务完成条件：玩家通过低温舱区、海滩回访和终端字段交叉验证，基本确认自己与 Subject 07、保护仓和 Project ECHO 有直接关系。

## 主线任务 10：父母权限与最终真相

建议解锁等级：5。

触发条件：玩家获得 Subject 07 保护仓接口片、实验日志碎片或足够权限进入更深区域。

主要地点：`地下实验设施：低温休眠舱区`、`地下实验设施：共振控制室`、`主共振核心室：最终区域`。

关键道具：`父母权限覆盖卡`、`父母录音带`、`Project ECHO 人员名单残页`、`主共振核心频率纸带`。

玩家目标：

- 确认父母与 Project ECHO 的关系。
- 理解父母既参与实验，也在事故中试图保护 Subject 07。
- 获得主共振核心的状态和关闭/稳定所需条件。
- 将父母权限覆盖卡、人员名单残页、父母录音带和安全弹射记录互相核对，避免单一道具洗白或定罪父母。
- 回访地表 NPC 征询代价，但不让任何 NPC 替玩家解释完整流程。
- 决定是否继续前往核心室。

关键线索：

- `parents_authority`
- `parents_recording`
- `subject_07_confirmed`
- `project_echo_responsibility`
- `main_resonance_core_state`

NPC 提示逻辑：

- Lab Terminal 给事实记录。
- 父母录音给动机和情感。
- Venn 给破碎记忆反应。
- Orin 给罪疚和代价。
- Mara 给伦理与禁忌视角。

禁止提前透露：无。此阶段已进入最终真相，但仍应避免一次性长篇说明，保持片段揭示。

任务完成条件：玩家通过多份记录、录音和地点证据理解完整真相，并获得进入最终选择的关键条件。

## 主线任务 11：离开、稳定或留下

建议解锁等级：5。

触发条件：玩家抵达主共振核心室，获得关闭流程残片、回声晶片、父母权限覆盖卡和核心频率纸带中的关键组合。

主要地点：`主共振核心室：最终区域`。

关键道具：`回声晶片`、`核心室手动关闭流程残片`、`主共振核心频率纸带`、`父母权限覆盖卡`。

玩家目标：

- 评估关闭归潮场、稳定归潮场或部分关闭的后果。
- 根据玩家掌握的线索和 NPC 反应作出最终选择。
- 处理玩家身份、父母责任、岛民安全和归潮未来之间的冲突。

可能结局方向：

- 关闭：解除归潮，但可能释放长期封闭的风险或破坏岛屿稳定。
- 稳定：保留部分封闭，保护岛民但牺牲完全自由。
- 部分关闭：开放有限通道，风险和希望并存。
- 放弃操作：维持现状，玩家可能选择继续寻找更安全方案。

任务提示限制：最终阶段可以引用 Lab Terminal 记录和父母录音，但仍不应变成攻略式答案。NPC 应表达立场，而不是替玩家选择。

## 支线任务 A：Nia 的蓝色小石头

建议解锁等级：1 到 2。

触发条件：玩家听见井边回声传闻，或 Nia 提到自己见过蓝色小石头。

主要地点：`静潮村：公告板、水井和发电机`、`草药屋：Lira 的诊疗空间`、`长老屋：Mara 的禁忌和祭歌`。

关键道具：`Nia 的蓝色小石头`、`Mara 的贝壳护符`、`Lira 的样本瓶`。

任务目标：温和询问 Nia，取得蓝色小石头，让 Lira 检查是否危险，再向 Mara 询问蓝脉禁忌。

探索改写：该支线不应只靠询问 Nia。玩家应先观察井边贝壳圈、孩子传话游戏或公告板井边禁令，再用温和态度取得蓝色小石头。之后将小石头带到草药屋样本柜或井边回访，观察它与头痛、回声或贝壳风铃的关系，最后请 Lira/Mara 验证危险边界。

作用：低剧透引出蓝色水晶、儿童禁忌、井边回声和 NPC 关系。该支线不应直接推进地下设施，但能提高 Lira、Nia、Mara 相关信任。

## 支线任务 B：Karo 的旧信与受潮航海本

建议解锁等级：2。

触发条件：玩家调查码头旧船、发现航海残页或追问 Karo 离岛失败。

主要地点：`村口码头：离岛失败证据`。

关键道具：`Karo 的受潮航海本`、`Karo 写给亡妻的旧信`、`磁化船钉`。

任务目标：在不强迫 Karo 的情况下理解他的失败和创伤。玩家可以把磁化船钉、航海残页和旧信作为谈话入口。

探索改写：玩家应先调查旧船刻痕、船底蓝灰粉末、无线电误响和磁化船钉，再决定是否触碰 Karo 的私人旧信。Karo 的信任不应来自玩家“问对问题”，而应来自玩家先看见证据、再尊重他的沉默。

作用：强化 Karo 个人线，让他的“别出海”从阻碍玩家变成有证据的警告。

## 支线任务 C：Venn 的碎纸地图

建议解锁等级：2 到 3。

触发条件：玩家获得失效指南针、航海残页、雾林传闻或 Karo 的航海本。

主要地点：Venn 废屋，村庄边缘。

关键道具：`Venn 的碎纸地图`、`Venn 涂黑的研究页`、`旧无线电录音`。

任务目标：帮助 Venn 对照地图、码头记录和无线电噪声，让他提出“边界折回”的猜测。

探索改写：玩家需要把失效指南针、航海残页、Karo 航海本或石碑拓片带到 Venn 废屋，让墙上地图发生增删变化。Venn 只验证“重复图案”，不应直接给出地下设施答案。

作用：把经验线索转化为理论线索，为后续雾林石碑和灯塔下层做铺垫。

限制：Venn 不能在此支线确认 Subject 07。

## 支线任务 D：Mara 的祭歌木片

建议解锁等级：3。

触发条件：玩家获得雾林石碑拓片或尊重潮民禁忌。

主要地点：`长老屋：Mara 的禁忌和祭歌`、`雾林：三块石碑与旧轨道`。

关键道具：`Mara 的祭歌木片`、`雾林石碑拓片`、`雾林风铃碎片`。

任务目标：让 Mara 解释祭歌中“三块石头”“蓝骨”“铁塔”的象征意义，并把它们与雾林石碑和灯塔方向对应起来。

探索改写：玩家需要先取得雾林风铃碎片、三块石碑拓片或井边纸卷，才有资格看见祭歌木片排序。Mara 可以解释某一句的文化意义，但木片顺序和灯塔方向应由玩家自己对照。

作用：让潮民传统不是装饰，而是推进主线的另一套线索语言。

## 支线任务 E：Orin 的赎罪证据

建议解锁等级：4。

触发条件：玩家进入灯塔区域，发现灯塔看守日志、旧门禁牌或烧焦钥匙环。

主要地点：`废弃灯塔：Orin 的守门区域`、`废弃灯塔：隐藏下层入口`。

关键道具：`灯塔看守日志`、`Orin 的旧门禁牌`、`Orin 的烧焦钥匙环`、`灯塔旧钥匙`。

任务目标：不是审判 Orin，而是让玩家理解他为什么守门、为什么隐瞒、为什么害怕玩家深入。

探索改写：玩家应通过灯塔楼梯刻痕、灯室光斑、看守日志、烧焦钥匙环和旧门禁牌残角拼出 Orin 的旧罪轮廓。Orin 交出钥匙应是玩家拿到足够地点证据后的验证结果，而不是对话说服奖励。

作用：使 Orin 交出旧钥匙更合理，也让灯塔下层开启具备情感和逻辑重量。

## 支线任务 F：Lira 继承的旧病历夹

建议解锁等级：3。

触发条件：玩家帮助 Lira 处理回声病、获得样本瓶或蓝色小石头，或已调查雾林边缘。

主要地点：`草药屋：旧病历和样本柜`。

关键道具：`Lira 继承的旧病历夹`、`Lira 的样本瓶`、`回声病病历：早期病症记录`。

任务目标：让 Lira 承认大震夜后的旧病例比普通回声病更严重，并把地下呼救传闻、蓝光和病症联系起来。

探索改写：玩家应带回 Nia 的蓝色小石头、井边回声触发记录、蓝苔压痕拓片或样本瓶观察结果。Lira 通过新增病历栏目验证这些证据的相关性，而不是直接讲出地下异常原因。

作用：把医学线从早期症状推进到中期历史异常。

## 任务状态与解锁等级映射

`unlocked_story_level` 建议按以下方式推进：

- 0：开场前或无剧情进展，仅能看到生活类地点和普通传闻。
- 1：玩家醒来，获得铭牌、指南针、航海残页，进入静潮村。
- 2：玩家完成村庄问询，调查码头、Karo 航海本、灯塔传闻和基础回声病线索。
- 3：玩家进入雾林线，获得石碑拓片、Mara 祭歌木片、Lira 继承的旧病历夹、Venn 研究页等中期证据。
- 4：玩家说服 Orin，进入灯塔下层和地下设施前段，确认 Project ECHO 与设施存在。
- 5：玩家进入人体观测区、低温休眠舱区、共振控制室和主核心线，确认 Subject 07、父母权限和最终选择。

## 任务提示系统建议

当玩家问“我该做什么”时，后端可优先根据 `current_quest` 返回任务提示，而不是让普通 RAG 自由回答。

推荐判断顺序：

1. 如果玩家缺少当前任务必要道具，提示最近的可调查地点。
2. 如果玩家已有道具但未在对应地点使用，提示“带回哪里试”。
3. 如果玩家已在地点触发反馈但未组合证据，提示“和哪个道具/记录对照”。
4. 如果玩家已有组合证据但未询问对应 NPC，提示“找谁验证”，而不是“找谁问答案”。
5. 如果玩家询问过 NPC 但缺少下一地点，提示下一地点。
6. 如果玩家尝试提前追问高剧透内容，提示“还缺少地点证据或道具反馈”，而不是给答案。
7. 如果玩家已经进入高解锁等级，允许 NPC 对同一线索给出更深解释，但仍应优先引用玩家亲自拿到的证据。

示例：

- 有 `failed_compass` 但没有 `dock_marks_checked`：提示回村口码头看旧船刻痕和船底粉末。
- 有 `blue_stone` 但没有 `lira_sample_check`：提示先带去草药屋样本柜隔离观察，再找 Lira 验证。
- 有 `well_echo_rumor` 但没有 `well_shell_feedback`：提示带贝壳护符或风铃线结回井边，不要直接喊名字。
- 有 `three_steles_ring_symbol` 但没有 `steles_order_verified`：提示把三块拓片与祭歌木片顺序对照，再找 Mara 或 Venn 验证。
- 有 `old_key` 和 `steles_rubbing` 但没有 `door_access_triad`：提示还需要旧门禁牌残角或灯室光斑后的检修盖线索。
- 有 `protective_pod_fragment` 但没有 `terminal_subject_query`：提示寻找可读取旧设施记录的终端。
