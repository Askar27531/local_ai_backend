# 15 岛屿时间线

> 本文件用于把世界观、NPC 经历、地点和主线事件串成因果链。玩家询问“这件事发生在什么时候”“谁先知道什么”“大震夜前后有什么变化”时，可从这里检索。

## 潮民早期与蓝脉禁忌（解锁1）

很久以前，潮民就在归潮岛上生活。他们发现雾林、山体和海潮之间存在异常联系，也发现地下蓝色石头会影响梦境、方向感和身体状态。潮民没有现代科学语言，于是把这种地下蓝色矿脉称为蓝脉。

蓝脉禁忌不是凭空迷信，而是长期经验：不要把蓝脉石带回家，不要在蓝光亮起时大声喊名字，不要越过雾林石碑，不要在海雾中沿着旧脚印走。Elder Mara 是这些禁忌的主要保存者，Nia 则从她那里听到许多故事。

这一阶段普通 NPC 可以知道传说，但不能解释水晶共振或地下装置。

## 外来者第一次公开登岛（解锁2）

外来者最初以气象观测、无线电测试、矿物调查或医疗支援等名义接近静潮村。他们带来药品、金属工具、发电设备和村民没见过的仪器，因此早期并不完全被排斥。

一些村民认为外来者会改善生活，另一些人则担心他们在雾林和山体附近活动太频繁。年轻时的 Mara 反对他们接触蓝脉，并亲眼见过他们把蓝脉当成资源和工具。Karo、Orin 和 Lira 这一代人没有亲历外来者公开登岛，他们知道这段历史主要来自长辈讲述、旧病历、码头残页、灯塔遗物和村中传闻。

普通村民不知道这些外来者真正属于赫利俄斯结社，也不知道 Project ECHO 的完整目的。

## Project ECHO 建设期（解锁4）

Project ECHO 建设期发生在外来者深入山体和灯塔下层之后。地下设施逐步形成，灯塔被改造为地表节点，雾林边界与地下蓝脉之间的联系被纳入实验系统。

这一时期出现了晶体样本室、观测区、低温休眠区、共振控制室和通往主共振核心的工程结构。Venn 当前能接触到的多是这一时期留下的残缺资料，Orin 当前能见到的则是事故后仍残留的门禁、标记或维护路径，Lab Terminal 保存残缺记录。

该阶段信息不应由 Karo、Nia 等普通 NPC 解释。玩家应通过 Orin、Venn、地下设施和 Lab Terminal 逐步确认。

## 大震夜与归潮增强（解锁3）

大约 80 年前，大震夜发生。村民记得山体震动、灯塔蓝光、海水异常、雾持续不散和多人失踪。潮民把它理解为蓝脉禁忌被破坏后的反噬，地表村民把它记作灾难，地下记录则可能把它称为事故或核心失稳。

大震夜之后，归潮现象从偶发变得稳定。海雾更频繁，罗盘和无线电更容易失效，回声病病例增加，外来者不再公开出现。Mara 更严格地守护禁忌，前代草药师开始记录异常病症，旧守塔职责也从那一夜之后变成沉重的禁令。Karo 的离岛失败和 Orin 的守塔罪疚都发生在更后来的年代，是这场灾难的长期余波。

这一阶段能被多个 NPC 从不同角度讲述，但不能在中期直接揭示实验全貌。

## 大震夜后的代际记忆（解锁2）

大震夜距离当前约 80 年，因此并非所有主要 NPC 都能亲历外来者公开活动。岛上的历史被分成几种记忆来源：

- Mara 是第一代亲历者。她十几岁时见过大震夜，把灾难、失踪和蓝脉禁忌保存为祭歌和边界故事。
- Karo 是后果亲历者。他出生在大震夜之后，亲身经历的是持续几十年的离岛失败、海雾增强和码头记录。
- Orin 是二次事故亲历者。他没有参与 Project ECHO 建设期，但年轻时接触事故后残留的灯塔下层，并因一次错误开门而背负罪疚。
- Lira 是档案继承者。草药屋保存前代草药师、母亲和她自己的三代病历，把大震夜后的伤者记录延续到当前回声病观察。
- Venn 是资料污染者。他研究旧档案和异常录音后产生记忆错置，无法确认哪些片段来自自己，哪些来自残缺记录和回声病。
- Nia 是传闻接收者。她不懂历史全貌，却从大人争吵、Mara 故事和井边回声中听见碎片。

这使大震夜不是单一回忆，而是压在不同世代身上的长期伤口。

## Karo 多次离岛失败（解锁1）

Karo 年轻时不相信归潮无法突破，曾多次驾驶木船离开岛屿。他的失败记录让他从最勇敢的渔夫变成最不愿谈海的人。

离岛失败经历让 Karo 知道海雾、罗盘、无线电、灯塔蓝光之间存在关联，但他不懂科学解释。他对玩家出海的反对不是单纯胆小，而是来自反复被归潮拖回来的创伤。

Karo 的经历在时间线上发生于大震夜之后，证明归潮增强并不是单一夜晚的传闻，而是长期影响村民生活的现实。

## Venn 失忆与废屋研究（解锁3）

Venn 的失忆发生在他接触旧资料或归潮异常之后。他的废屋研究把地图、雾林石碑、灯塔蓝光、回声病和 Project ECHO 片段联系起来，但他的记忆碎裂，无法提供完整答案。

Venn 可能曾接近真相，也可能曾参与事故后对旧资料的整理或研究。他自己无法确认。因此他的时间线是最不稳定的：有些片段来自亲历，有些来自读取记录，有些可能来自回声病造成的记忆残留。

玩家应把 Venn 当成线索拼图，而不是完整证人。

## Orin 守塔与旧门封闭（解锁2）

大震夜后，旧守塔职责在村中断续传承。Orin 年轻时继承了这份职责，接触到事故后残留的灯塔下层入口、旧门禁和蓝光导管。他的行为表面像守塔，实际是在阻止村民、孩子和好奇外来者靠近下层入口。

Orin 守塔不是因为他掌握真相后想控制别人，而是因为他年轻时在一次灯塔蓝光夜打开过外层门，导致搜救者或好奇者失踪。他的沉默和冷淡来自赎罪，也来自对玩家承受能力的判断。

随着玩家获得雾林石碑拓片、旧钥匙、铭牌和地下线索，Orin 才会逐渐松动。

## 玩家漂流醒来（解锁1）

游戏开始时，玩家在漂流海滩醒来，失去记忆，随身携带破损金属铭牌和失效指南针。村民从不同角度看待这件事：Karo 把玩家视为又一个被海送回的人，Lira 把玩家视为特殊病人，Nia 觉得玩家像她见过的人影，Mara 警惕玩家身上是否带着外来者的旧债。

玩家醒来的事件把过去时间线重新拉到现在。早期 NPC 不能解释玩家真实身份，只能根据症状、物品和传闻给出有限判断。

## 灯塔下层重新打开（解锁4）

当玩家集齐足够线索并进入灯塔下层时，地表传闻开始与地下结构对齐。雾林石碑不再只是禁忌，灯塔蓝光不再只是传闻，Orin 的沉默和 Venn 的碎片也开始指向同一个旧设施。

这一阶段玩家可以确认 Project ECHO 与灯塔、地下设施、蓝脉共振存在关系。但 Subject 07、父母身份、保护仓和最终关闭方法仍应分层揭示。

地表 NPC 的反应应出现变化：Karo 更抗拒，Lira 更谨慎，Orin更沉重，Venn 更不稳定，Mara 更强调代价。

## 地下核心与终局选择（解锁5）

终局阶段，玩家进入主共振核心相关区域，Lab Terminal、实验日志、父母录音带和核心控制台共同揭示最终真相。此时 Project ECHO、Subject 07、保护仓、安全弹射、父母权限和归潮场关闭流程才可以被完整拼合。

即使到了终局，信息也不应由普通 NPC 像报告一样讲完。Lab Terminal 可以提供事实，父母录音提供动机，Venn 提供破碎回忆，Orin 承担罪疚反应，Mara 提供道德和禁忌视角。

终局时间线的作用不是单纯解释过去，而是让玩家决定如何面对旧设施、岛民安全和归潮场的未来。
