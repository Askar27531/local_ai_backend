# 02 特殊水晶矿脉

> 本文件用于描述归潮岛地下蓝脉、水晶异常、回声病、灯塔节点和主共振核心之间的关系。早期 NPC 只能讲经验和症状，中期 NPC 可以讲观察与推测，后期深层角色和 Lab Terminal 才能讲装置和核心机制。

## 蓝脉石：潮民说法（解锁1）

归潮岛地下存在一种蓝色矿石。潮民称它为“蓝脉石”“潮心石”或“岛的骨”。在潮民传统里，蓝脉不是财宝，而是岛本身的一部分，不能随便挖掘，也不能被带离它原本所在的地方。

普通岛民只知道蓝色石头会在潮湿夜晚微微发光，长时间靠近容易头痛，小孩不能把蓝色碎石带回家，雾林深处的石碑与蓝脉有关，大震夜之后蓝光、海雾和回声病变得更频繁。

这些说法是潮民长期经验形成的禁忌，不是科学解释。Mara 会用“蓝脉醒来”“海会记得名字”“岛的骨被挖伤”来描述现象；Nia 会记得大人不让孩子碰蓝色石头。

## 潮民禁忌的实际意义（解锁1）

潮民禁忌包含许多看似神秘但实际有效的经验规则：蓝脉发光时不要大声喊自己的名字，不要把蓝色碎石带回家，不要越过雾林石碑，不要在海雾中沿着旧脚印走，不要在灯塔蓝光夜靠近井边。

这些规则并不能解释蓝脉原理，但能降低暴露风险。不要喊名字，可能是为了避免回声病患者在强干扰中产生身份错乱；不要带走碎石，是为了减少长期接触；不要越过石碑，是为了避开矿脉边界和地下通风区域。

Mara 可以讲这些禁忌，Lira 可以从症状角度部分理解，Venn 可以在中期把它们看作经验科学的民间版本。

## 蓝脉自然状态（解锁1）

在自然状态下，蓝脉石的影响较弱，通常只在近距离、潮湿环境、雾季、潮汐变化或局部裂缝附近表现明显。

可能出现的现象包括：罗盘靠近蓝色碎片时偏转，人长时间接触后出现耳鸣、头痛和重复梦境，雾林部分植物生长异常，动物避开某些矿脉裂缝，短波无线电出现低频噪声，井边回声比平时更清晰。

自然状态下的蓝脉不足以解释整座岛无法离开。它更像一处长期低强度异常源，会影响人的身体和环境，但不会单独形成归潮场。

## 蓝色碎片与局部暴露（解锁2）

蓝色水晶碎片是蓝脉矿体的小块脱落物，常见于雾林边缘、地下通风口附近、潮湿裂缝和被外来者挖掘过的区域。碎片通常发出极弱蓝光，靠近时可能导致耳鸣、头痛、手指发冷、短暂熟悉感或重复梦境。

Nia 的蓝色小石头属于低强度局部暴露线索。它不会让玩家立刻理解地下核心机制，却能让 Lira、Mara 和玩家意识到：蓝色石头不是普通漂亮矿物。

长期贴身携带碎片可能加重回声病症状。Lira 会建议收走样本并记录接触时间；Mara 会要求把蓝脉石还回边界附近；Karo 会本能地不愿靠近。

## Lira 对蓝脉的医学观察（解锁2）

Lira 不是科学家，但她长期记录村民病症。她发现，回声病患者往往接触过雾林、灯塔蓝光、蓝色碎石、井边回声或海雾最浓的区域。

她不能证明蓝脉石会改变记忆，但她能观察到症状规律：头痛常在蓝光夜加重，梦境会重复同一片海滩或同一条走廊，部分患者醒来后短暂忘记亲人名字，方向感混乱常伴随耳鸣。

Lira 能提供“蓝脉可能影响人体”的中期判断，但不能独立解释共振场、人体实验、地下舱体或玩家身上的旧编号。

## 回声病暴露阶段（解锁2）

回声病可以按暴露程度分为几个阶段：

第一阶段是轻度暴露：头痛、耳鸣、梦境重复、靠近蓝色碎片时不适。

第二阶段是环境触发：进入雾林、靠近灯塔、听见井边回声或海雾中无线电噪声时，出现方向感混乱和短暂幻听。

第三阶段是记忆干扰：患者会看到模糊过去画面，对从未去过的地点产生熟悉感，或短暂忘记自己正在做什么。

第四阶段是深度暴露：接近地下设施、灯塔下层或核心装置相关区域时，可能出现身份错位、强烈幻觉、神经性失忆和长期记忆损伤。

普通村民多停留在第一、第二阶段。玩家因为旧编号、长期休眠和地下舱体经历，症状更复杂。

## 为什么影响记忆（解锁3）

蓝脉对记忆的影响不是简单“删除记忆”。更准确地说，它会干扰人在强压力、强方向错乱或重复声音中的记忆编码，使某些片段被放大、折回、错位或重复出现。

这解释了回声病患者为什么会反复梦见同一地点，为什么海雾中的声音像是“另一个自己”，为什么玩家靠近某些地点时会出现不属于当前时间的片段。

Venn 可以用“记忆残留”“边界折回”“回声不是声音”来解释这一层。Lira 可以承认这是她无法完全解释的神经异常。Lab Terminal 后期可以显示人体观测记录。

## 为什么影响方向（解锁3）

蓝脉会影响方向感有两层原因。第一层是物理层面：蓝脉异常会干扰罗盘、金属物和无线电，使仪器不可靠。第二层是感知层面：人在海雾、低频噪声和蓝脉暴露中会产生空间判断错误，以为自己一直朝外走，实际已偏回岛内。

归潮场形成后，这种方向干扰被扩大到近海边界。离岛者不是撞上一堵墙，而是在仪器失效、视觉遮蔽和短暂失忆中被引导回海滩、码头或雾林边缘。

Karo 的经验说法“海把人送回来”和 Venn 的理论说法“坐标被折回原点”，其实描述的是同一现象的不同层级。

## 为什么影响无线电（解锁3）

蓝脉会让短波无线电出现低频噪声、重复信号和断续人声。自然状态下，这种干扰只在雾季、矿脉裂缝、灯塔蓝光夜或强潮汐时明显。装置激发后，干扰范围扩大到整座岛和近海。

无线电噪声之所以像人声，不一定代表真的有人在说话。它可能混合了旧信号、回声病患者的感知误差、设备重复播放和共振场对声音记忆的干扰。

Venn 会把旧无线电录音当作边界证据，Karo 会讨厌这些声音，Lira 会担心长时间播放会加重头痛。

## 为什么形成海雾（解锁3）

海雾是归潮现象最明显的外部表现，但它不只是普通水汽。蓝脉共振会改变近海局部温差、潮湿空气流动和感知状态，使雾看起来像突然升起、持续过久、方向感极差。

早期 NPC 不应解释海雾机制。Karo 可以说海雾会骗人，Mara 可以说海把名字藏起来，Venn 可以怀疑海雾与边界场有关，Lab Terminal 后期可显示环境观测字段。

海雾的作用是遮蔽视觉、干扰时间感、放大无线电噪声，并让离岛者更容易被归潮边界折回。

## 雾林石碑与蓝脉边界（解锁3）

雾林三块石碑位于蓝脉边界附近。潮民把它们当成禁忌标记，提醒人不要继续深入。赫利俄斯结社后来发现，石碑所在区域与地下蓝脉和地表边界天然对应，于是把这些位置纳入 Project ECHO 的边界校准。

石碑图案组合后形成闭合环形符号。Mara 认为这是边界警告，Orin 认为它与灯塔下层入口有关，Venn 认为它可以解释归潮场的闭合结构。

这三种解释并不冲突：禁忌、入口和边界都是同一个地点在不同知识体系下的意义。

## 灯塔节点与蓝脉放大（解锁4）

废弃灯塔被赫利俄斯结社改造成地表控制节点，用于校准和放大地下蓝脉的共振。灯塔蓝光不是普通灯光，而是地下主共振核心通过地表节点泄漏出的可见现象。

灯塔节点有三种功能：投射核心频率、辅助边界定位、提供地下设施维护入口。它将自然蓝脉异常从局部现象放大为可覆盖海岸和近海区域的系统。

Orin 可以在后期承认灯塔不是普通灯塔；Venn 可以推测灯塔与边界折回有关；Lab Terminal 可以显示 `SURFACE NODE` 或 `RESONANCE FIELD` 片段。

## 装置激发状态（解锁4）

只有当蓝脉被特殊装置激发后，才会产生大范围影响。自然蓝脉只能造成局部头痛、梦境和仪器偏转；装置激发会让影响覆盖村庄、雾林、灯塔和近海边界。

装置激发后的表现包括罗盘和无线电大范围失效、海雾异常增强、人体方向感和短时记忆受到干扰、潮流路径出现不自然变化、离岛者更容易被引导回岛屿边界内，长期暴露者出现严重回声病。

这一层信息不应由普通村民解释。Orin 和 Venn 可以用模糊方式提到，Lab Terminal 可以在后期给出明确记录。

## 主共振核心（解锁5）

地下深处存在一枚巨型水晶，是整条蓝脉矿体的核心。赫利俄斯结社将其称为 Main Resonance Core。

主共振核心不是普通矿石，而是可以响应特定频率并放大能量的核心节点。关键实验中，研究人员试图让多个共振装置同步，诱导巨型水晶进入稳定状态。

实验失败后，巨型水晶被过度激活，引发爆炸和地震，并使归潮场进入长期失控状态。主共振核心仍在低频运转，是归潮场持续存在的根本原因。

本信息属于最终真相内容，应主要由 Lab Terminal、实验日志、Venn 后期片段、Orin 后期反应或隐藏真相文件揭示。

## 主共振核心为什么无法自然停下（解锁5）

事故后，主共振核心没有完全停机，而是进入低功率、自维持的残留共振状态。灯塔节点损坏后无法正常断开，雾林边界和地下蓝脉仍保持闭合回路。

归潮场持续的原因是：核心、灯塔节点、蓝脉矿体、雾林边界和岛屿地形共同形成一个残缺但稳定的循环。破坏某一个表面节点不能解除全部归潮，反而可能引发新的不稳定。

这解释了为什么终局不能简单炸毁灯塔或拿走水晶碎片。玩家必须面对主共振核心和控制流程。

## 回声晶片的作用（解锁5）

回声晶片是主共振装置的一部分，使用蓝色晶体和金属框架结合制成。它可以与巨型水晶产生低频共振，是稳定、降频或关闭归潮场的关键部件之一。

回声晶片不是万能钥匙。它需要与主共振核心频率纸带、父母权限覆盖卡和核心室控制流程共同使用。晶片损坏或错误放置可能导致核心频率波动。

Lab Terminal 可以显示晶片状态；Venn 可以用比喻说它像“回声的牙齿”；Orin 会警告玩家不要乱动。

## 与 Project ECHO 的关系（解锁4）

Project ECHO 并不是凭空制造归潮，而是把蓝脉的自然异常系统化、放大化和武器化。蓝脉本来只会造成局部影响；Project ECHO 用灯塔节点、地下装置和人体观测把它变成可覆盖全岛的实验系统。

这也是为什么潮民禁忌、Lira 病历、Karo 航海记录、Venn 地图、Orin 灯塔钥匙和 Lab Terminal 日志能互相拼合。它们分别记录了同一个系统在不同层面的表现。

赫利俄斯结社的罪责不在于发现蓝脉，而在于把蓝脉当成工具，把岛民和人体反应当成实验变量。

## 与保护仓和 Subject 07 的关系（解锁5）

Subject 07 的保护仓设计，是为了在蓝脉共振暴露中保护人体，避免神经损伤过深。主人公母亲参与了人体保护和低温休眠系统，并为 Subject 07 设置更高保护优先级。

事故中，主共振核心过载，人体观测区出现严重神经反应，保护仓封闭并启动低温休眠。80 年后，核心波动或小地震触发安全弹射，保护仓破损，玩家在海滩醒来。

因此，玩家失忆不是单一原因造成，而是低温休眠、长期蓝脉场暴露、保护仓弹射冲击和归潮场波动共同作用的结果。

## 武器化企图（解锁5）

赫利俄斯结社曾试图将蓝脉共振场用于大范围通信干扰、导航干扰、群体感知压制和区域封锁。Project ECHO 是他们最重要的验证计划。

本设定仅作为虚构游戏背景，不提供任何现实可执行技术细节。游戏文档中不描述装置制造、参数配置或现实操作步骤。

该信息属于高解锁等级内容，不能被 Karo、Nia 或早期 Lira 直接解释。Orin 和 Venn 可以在后期表达恐惧和猜测，Lab Terminal 可以显示残缺计划字段。

## 当前状态（解锁4）

事故发生后，主共振核心仍在地下低频共振。灯塔方向的蓝光、海雾增强、无线电噪声、回声病和归潮现象都与这种长期失控状态有关。

归潮场不是始终稳定。潮汐、小地震、灯塔蓝光增强、地下装置故障、回声晶片状态变化都可能使它短暂波动。

玩家保护仓的弹射与一次小地震和地下场强波动有关，但这一点属于后期真相，普通 NPC 不应提前知道。

## NPC 可解释层级（解锁2）

不同 NPC 对蓝脉的解释必须保持层级差异。

Karo：只能从经验讲，不喜欢蓝色石头和灯塔蓝光，知道海雾、罗盘和出海失败有关，但不解释原理。

Lira：能从症状和病历讲，知道蓝色碎片可能加重头痛、梦境和幻听，但不能解释地下核心装置。

Nia：只能讲孩子看到的蓝光、小石头、井边回声和大人禁忌。

Elder Mara：能讲蓝脉禁忌、石碑边界、大震夜和外来者破坏禁忌，但不用科学词。

Orin：能在中后期承认灯塔、蓝光和地下设施有关，但不应一次性讲完核心机制。

Venn：能讲边界折回、记忆残留、罗盘异常和 Project ECHO 片段，但必须保持不确定。

Lab Terminal：能显示最明确的技术记录，但只在对应权限、地点和解锁等级下输出。
