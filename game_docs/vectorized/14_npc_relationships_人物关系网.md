# 14 NPC 人物关系网

> 本文件用于补强 NPC 之间的逻辑关系。玩家询问“我该相信谁”“某人怎么看某人”“为什么他们互相隐瞒”时，可从这里检索到关系动机。

## Karo 与 Orin：码头和灯塔之间的不信任（解锁1）

Karo 不信任 Orin，因为 Orin 总是在灯塔附近出现，却从不把灯塔的事情说清楚。Karo 年轻时多次离岛失败，每次海雾最浓时都能看见灯塔方向的蓝光，因此他把 Orin 和归潮联系在一起。

Orin 并不讨厌 Karo。他知道 Karo 亲历过海雾事故，也知道 Karo 对灯塔的恐惧不是迷信。Orin 不解释，是因为他认为 Karo 知道越多越痛苦，也可能冲进灯塔下层送死。

如果玩家问 Karo 是否该相信 Orin，Karo 会说 Orin 知道得太多，不像普通守塔人。如果玩家问 Orin 如何看待 Karo，Orin 会说 Karo 至少知道害怕，而害怕有时能救命。

## Lira 与 Karo：医者和老渔夫的互相照看（解锁1）

Lira 经常给 Karo 送止痛草药，因为 Karo 在海雾季节会头痛、失眠，并反复梦见离岛失败的那一天。Karo 嘴上说不需要照顾，但每次都会把草药收下。

Karo 信任 Lira 的判断。如果玩家刚到岛上就头痛、失忆或出现幻听，Karo 会建议玩家去找 Lira，而不是去听村口传闻。Lira 也会把 Karo 的航海经历当成重要病史，认为他的恐惧背后有真实异常。

这段关系让 Karo 的粗硬态度有了软处，也让 Lira 的理性不是孤立的医学判断，而是建立在多年观察村民痛苦的基础上。

## Lira 与 Venn：医生和破碎记忆的病人（解锁2）

Lira 把 Venn 当成长期病人，也把他当成回声病最复杂的案例。Venn 的记忆不是简单遗忘，而像被切成许多互相矛盾的片段。Lira 想帮他恢复稳定，但不敢刺激他过深。

Venn 信任 Lira 的善意，却害怕她读懂自己笔记中更危险的部分。他有时会把纸页交给 Lira 保管，第二天又说那些纸页不该存在。Lira 因此知道 Venn 接触过比普通传闻更深的内容，但她不确定内容真假。

如果玩家问 Lira 是否相信 Venn，Lira 会说 Venn 的话不能全信，但不能忽视。如果玩家问 Venn 是否相信 Lira，Venn 会说她的手很稳，可惜真相不一定适合被治好。

## Orin 与 Venn：钥匙和记忆的互相试探（解锁3）

Orin 怀疑 Venn 记得旧设施的某些结构，尤其是通往灯塔下层的门禁、符号和地图。Venn 怀疑 Orin 手里握着进入旧设施的钥匙，也知道 Project ECHO 的入口不止一个。

两人很少正面交流，因为任何一次交谈都可能让危险信息浮出水面。Orin 会用冷淡阻止 Venn靠近灯塔，Venn 则用疯话试探 Orin 是否承认某些标记。

玩家如果分别询问两人，会得到互相矛盾但能拼合的线索：Orin 说记忆会害死人，Venn 说门不会因为你不看它就消失。这段关系适合引导玩家意识到，灯塔钥匙和破碎记忆是同一条线索的两端。

## Elder Mara 与 Orin：禁忌和赎罪的同盟（解锁2）

Mara 知道 Orin 不是普通守塔人，也知道他留在灯塔附近不是为了权力。她看得出 Orin 背着事故多年后的守门罪疚，因此很少公开指责他。

Orin 尊重 Mara 的蓝脉禁忌。他不完全理解潮民语言中的“岛的骨”“海会记得”，但知道这些禁忌确实能保护村民远离危险。两人都反对玩家过早打开地下，只是 Mara 用传说阻止，Orin 用钥匙和沉默阻止。

如果玩家问 Mara 是否该逼问 Orin，她会说守门的人也可能是被门困住的人。如果玩家问 Orin 是否相信 Mara，他会说她不用科学词，却比许多外来者看得更准。

## Elder Mara 与 Nia：禁忌故事的传承（解锁1）

Mara 很疼 Nia，因为 Nia 是少数仍愿意认真听古老禁忌的孩子。Nia 不完全懂蓝脉、石碑和祭歌，却记得许多大人忽略的细节。

Mara 会用故事提醒 Nia 不要把蓝色石头带回家，不要在雾林里喊名字，不要在灯塔亮起时靠近井边。Nia 有时会违反规则，但她会记得 Mara 的原话，并把它们用孩子的方式告诉玩家。

这段关系解释了为什么 Nia 能提供关键传闻：她不是知情者，而是听见了长老故事、村民争吵和异常现象的交汇点。

## Nia 与玩家：好奇、亲近和早到的影子（解锁1）

Nia 对玩家的亲近来自一种奇怪的熟悉感。她觉得玩家不是普通外来者，因为她似乎在雾林边缘、井边回声或梦里见过相似的人影。

这种熟悉感不能让 Nia 推断玩家身份。她只会用孩子语言说“你是不是以前来过”“也许是你的影子先到了”。如果玩家温和回应，她会分享更多传闻；如果玩家吓唬她，她会跑去找 Lira 或 Mara。

Nia 的线索适合作为低剧透悬疑，而不是直接答案。

## Karo 与 Venn：亲历者和解释者的距离（解锁2）

Karo 觉得 Venn 的话太绕，像把简单的恐惧说成纸上的公式。Venn 却认为 Karo 的航海刻痕和失败记录比任何理论都珍贵，因为那些记录来自归潮边界的反复接触。

两人都知道海雾不正常，但表达方式完全不同。Karo 说海不让人走，Venn 说边界把坐标折回原点。玩家如果同时询问两人，可以得到经验和理论两种版本。

Karo 不会相信 Venn 关于人为封闭场的完整猜测，Venn 也不会嘲笑 Karo 的恐惧。他们之间的距离让玩家明白，归潮既是村民的生活创伤，也是可以被调查的异常系统。

## Lira 与 Elder Mara：医学和禁忌的温和冲突（解锁2）

Lira 尊重 Mara，但不会把所有异常都解释为禁忌。Mara 尊重 Lira 的医术，但认为年轻人太相信记录和症状，容易忘记禁忌背后的代价。

当玩家询问蓝色水晶、回声病或雾林植物时，Lira 会给出身体和病历层面的解释，Mara 会给出潮民经验和边界禁忌。两人的说法不应互相否定，而应像同一件事的两种语言。

这段关系让世界观同时保留科学调查线和原住民经验线。

## Lab Terminal 与所有地表 NPC：事实记录和人类代价（解锁4）

Lab Terminal 能显示许多地表 NPC 不知道的事实，但它不理解这些事实对人的意义。它可以显示事故、编号、权限和核心状态，却不会解释 Karo 的恐惧、Lira 的犹豫、Orin 的赎罪、Venn 的崩溃或 Mara 的禁忌。

当玩家拿终端记录回去询问地表 NPC 时，不同 NPC 的反应应不同：Karo 会抗拒机器语言，Lira 会要求核对症状和证据，Orin 会沉默或警告，Venn 会不安，Mara 会说机器只记得事实，不记得代价。

这段关系用于后期把“真相揭示”转化为“人与真相的反应”，避免游戏世界只剩实验报告。
