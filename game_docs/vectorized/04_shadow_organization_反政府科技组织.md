# 04 反政府科技组织：赫利俄斯结社

> 本文件用于补强 Project ECHO 背后的组织结构和历史。它属于高解锁内容，普通村民不应解释；主要由 Orin、Venn、Lab Terminal 或后期线索片段触发。

## 组织概述（解锁4）

赫利俄斯结社是一个虚构的反政府科技组织，由脱离国家研究机构、军工体系、私人实验室和情报承包网络的科学家、工程师、军官、资本代理人和政治极端分子组成。

该组织认为现有政府、伦理审查和国际秩序限制了科学发展，因此主张建立由技术精英控制的新秩序。他们不把自己视为恐怖组织，而自认为是“在旧世界崩坏前先掌握钥匙的人”。

赫利俄斯结社的科技水平远高于归潮岛地表社会。他们掌握地下工程、低温休眠、晶体共振、早期类计算控制系统、复杂实验设施建设、海上隐蔽补给和档案伪装能力。

组织内部并非完全统一。有些人追求能源和医学突破，有些人追求军事化应用，有些人只是被资源和职位吸引。Project ECHO 失控的根源之一，就是这些不同动机被强行放进同一套危险系统。

## 组织意识形态（解锁4）

赫利俄斯结社的核心信念是：科学不应受普通社会的恐惧、法律和道德拖累。他们认为大规模灾难、战争和国家崩溃迟早会发生，而掌握异常技术的人才有资格决定未来秩序。

这种意识形态让他们能把归潮岛居民视为“隔离环境变量”，把蓝脉禁忌视为“原始误解”，把人体观测称为“保护性研究”。他们最危险的地方不在于完全没有理想，而在于他们会用理想给伤害命名。

Project ECHO 的伦理坠落并非一夜完成，而是从“为了理解水晶”变成“为了控制边界”，再变成“为了验证压制能力”。主人公父母也是在这个过程中逐渐意识到自己参与的系统已经变质。

## 为什么选择归潮岛（解锁4）

大约 80 多年前，赫利俄斯结社通过异常磁场记录、旧航海日志、无线电干扰数据、失踪船只报告和少数海员的模糊证词，发现归潮岛附近存在特殊矿脉和异常边界现象。

归潮岛被选中的原因包括：

- 岛下存在巨型蓝脉矿体，适合进行晶体共振实验。
- 地理位置远离主要航线，方便隐蔽施工和补给。
- 岛上人口少，技术水平低，外界监管薄弱。
- 海雾、磁场异常和航海困难天然掩盖异常活动。
- 潮民已有蓝脉禁忌，可被组织误读为“长期低强度暴露记录”。

对赫利俄斯结社来说，归潮岛不是家园，而是天然实验场。对潮民来说，外来者不是带来进步的人，而是把岛的旧伤挖开的人。

## 登岛前期调查（解锁4）

赫利俄斯结社在正式登岛前，先派出多批调查人员。第一批伪装成海洋地磁研究者，记录罗盘异常和无线电噪声。第二批伪装成矿物勘探队，采集蓝色水晶碎片。第三批以医疗和传染病调查名义接触村民，记录头痛、失忆和梦境重复等症状。

这些前期调查形成 Project ECHO 的基础假设：蓝脉不只是矿物，它能影响仪器、记忆和空间判断。组织高层由此判断，蓝脉可以被改造成区域压制技术。

这解释了为什么草药屋三代旧病历、Karo 后来的航海记录、Venn 的碎纸地图和 Lab Terminal 的早期观测字段能互相对应。

## 对外伪装：气象、医疗、矿物和无线电（解锁4）

赫利俄斯结社最初以气象观测队、海洋地磁研究组、矿业勘探公司、无线电导航测试站和临时医疗支援队的身份登岛。

他们向村民提供药品、发电机、金属工具、维修技术和有限的外界物资，以换取进入山体、雾林、灯塔周边和海岸异常区域的许可。部分村民起初相信他们能帮助岛屿连接外界，改善医疗和供电。

伪装策略分为四层：

- 气象伪装：解释海雾观测和灯塔设备安装。
- 医疗伪装：解释人体检查、病历采集和隔离病房。
- 矿物伪装：解释蓝脉采样、地下开挖和运输箱。
- 无线电伪装：解释地表天线、灯塔节点和导航测试。

这些伪装让 Project ECHO 的多个模块能同时推进，也让后来的村民传闻变得碎片化：有人记得药物，有人记得金属箱，有人记得夜里的灯塔蓝光。

## 与潮民的早期接触（解锁4）

赫利俄斯结社并没有一开始公开敌对潮民。他们学习部分潮民语言，雇佣少数向导和搬运者，向村里提供医疗和修理服务，并试图把蓝脉禁忌重新解释为“原始矿物恐惧”。

Mara 所代表的长老群体反对外来者进入雾林深处和山腹。年轻一代中有人被药品、发电机和外界承诺吸引，认为外来者也许能打破孤岛困境。

冲突逐渐发生在三个问题上：外来者是否能挖蓝脉、是否能带走村民做检查、是否能改造灯塔。大震夜之后，潮民记忆中保留下来的不是组织名称，而是“外来者破坏了禁忌”。

## 地下设施建设方式（解锁4）

赫利俄斯结社在归潮岛地下修建大型实验设施，包括晶体样本室、人体观测区、低温休眠舱区、共振控制室、能量导流井、地下轨道通道、隔离病房、灯塔控制节点和主共振核心室。

建设方式分阶段进行：

1. 以矿物勘探名义开凿浅层通道。
2. 以灯塔维护名义铺设地表节点和电缆。
3. 以医疗支援名义建立观察室和隔离区。
4. 以无线电测试名义安装控制台、天线和频率设备。
5. 在深层蓝脉附近建设主共振核心室。

设施风格是 1950 年代工业金属结构与异常晶体技术混合：真空管控制台、纸带记录机、粗电缆、老式门禁、蓝色导管和半机械半晶体的共振设备。

## Project ECHO 总体结构（解锁4）

Project ECHO 是赫利俄斯结社在归潮岛进行的核心研究计划。它不是单一实验，而是由多个部门和模块共同推进的长期项目。

计划目标包括：研究蓝脉对磁场的放大效应，研究水晶场对人体记忆和神经活动的影响，测试水晶场是否可以干扰通讯和导航，测试人体是否能在场中保留方向感和身份记忆，探索水晶场的大范围压制能力。

Project ECHO 的名字来自研究人员对“记忆回声”的观察。实验对象在水晶场中会出现重复梦境、幻听、过去片段和身份错位。组织高层把这些症状视为可量化数据，而不是痛苦。

## Project ECHO 内部分工（解锁4）

Project ECHO 至少分为六个内部部门：

- 晶体共振组：负责蓝脉样本、巨型水晶、回声晶片和主共振核心。
- 地表节点组：负责废弃灯塔、雾林边界、地表天线和边界校准。
- 人体保护组：负责低温休眠、保护仓、安全弹射和神经损伤防护。
- 人体观测组：负责 Subject 编号、暴露实验、记忆测试和症状记录。
- 工程维护组：负责地下通道、门禁、电力、轨道、通风和灯塔维护。
- 安保与保密组：负责档案销毁、身份伪装、村民管控和外部补给。

这些部门之间存在冲突。人体保护组希望降低伤害，安保与高层希望推进实验，晶体共振组追求更大规模覆盖，工程维护组则不断报告系统不稳定。事故前的 Project ECHO 已经不是一项能被单个科学家控制的实验。

## 晶体共振组（解锁4）

晶体共振组负责蓝脉采样、频率测试、回声晶片制造和主共振核心激活。主人公父亲与该组关系最深，负责灯塔节点和核心频率校准。

该组最初关注能源、地磁异常和信号放大，但随着组织高层介入，研究目标转向大范围通讯瘫痪、导航干扰和区域封锁。

晶体共振组的错误在于过度相信模型。他们以为蓝脉可以像普通矿物或电路一样被稳定调频，却低估了巨型水晶、潮汐、地形和人体神经反馈之间的复杂耦合。

## 地表节点组与灯塔改造（解锁4）

地表节点组把废弃灯塔改造成 Project ECHO 的地表控制节点。灯塔原本用于航海标识，后来被加入蓝光导管、地下电缆、校准仪表、天线结构和隐藏下层入口。

灯塔的公开维护为地下工程提供伪装。村民以为外来者在修灯塔或做无线电测试，实际上他们在把灯塔接入主共振核心。

Orin 没有参与这一组的建设期。他接触到的是事故后残留的灯塔下层、旧门禁和维护记录。年轻时的一次错误开门让他意识到外来者留下的系统仍在伤人；因此他后来守着灯塔，不只是守秘密，也是守自己参与过的二次灾难。

## 人体保护组与主人公母亲（解锁5）

人体保护组负责保护仓、低温休眠、神经损伤防护和暴露后恢复方案。主人公母亲是该组核心人员之一。

她最初相信，如果蓝脉共振不可避免地影响人体，就必须建立保护机制，避免实验对象遭受不可逆损伤。她推动保护仓和低温休眠系统，并为 Subject 07 设置更高保护优先级。

她的责任在于：人体保护组的存在没有阻止人体观测，反而让组织相信实验可以继续扩大。保护机制本应降低伤害，却也成了继续实验的借口。

事故前，母亲试图修改 Subject 07 的保护仓权限和安全弹射条件。这一行为最终救下玩家，却没有阻止归潮灾难。

## 人体观测组与 Subject 编号（解锁5）

人体观测组负责 Subject 编号、暴露时间、记忆测试、梦境记录、方向感测试和身份稳定性评估。Subject 07 是其中一个关键编号。

研究对象包括自愿实验者、组织内部人员、被胁迫者、身份记录不完整的对象，以及被保护名义纳入观察体系的人。不同记录中对 Subject 的称呼冷冰冰，是因为组织试图把人转化为数据字段。

Subject 07 的特殊性在于，他既是实验记录的一部分，也是核心研究人员的孩子。这让父母权限、保护仓优先级和事故后弹射记录都变得异常。

人体观测组是真相中最难被原谅的部分。即使某些研究人员有保护动机，整个系统仍然侵犯了人的选择和尊严。

## 安保与保密组（解锁4）

安保与保密组负责伪装身份、压制村民疑问、销毁敏感记录、控制出入口、遮掩失踪事件和处理外界通信。他们是 Project ECHO 从秘密研究滑向组织暴力的关键部门。

他们把村民称为“地表人口变量”，把潮民禁忌称为“干扰叙事”，把失踪和回声病病例归类为“暴露副作用”。这种语言让伤害在档案中显得像普通技术问题。

部分实验日志缺失、人员名单残页烧毁、终端权限损坏，都可能与安保与保密组的事故前后销毁行动有关。

## 主人公父母与组织的关系边界（解锁5）

主人公父母不是赫利俄斯结社最高层，也不是完全无辜的旁观者。他们是 Project ECHO 的核心科研人员，对系统设计、实验推进和事故后果负有真实责任。

父亲负责晶体共振、灯塔节点和核心校准。他知道项目正在军事化，却试图从内部控制风险。母亲负责人体保护和低温休眠，她反对无保护暴露，却参与了 Subject 体系。

他们与组织的关系边界是：他们不是组织高层阴谋的唯一制定者，但他们的专业能力让阴谋得以执行。他们后来试图保护 Subject 07 和阻止数据外泄，是补救，不是赦免。

玩家在终局可以理解他们的爱，但不必原谅他们的责任。

## Venn 与组织的关系边界（解锁4）

Venn 与赫利俄斯结社的关系应保持一段时间的不确定性。他可能曾接触组织残档、外部研究资料、边界理论笔记或事故后残留记录，也可能只是被旧资料和回声病污染了记忆。

他熟悉 Project ECHO 这个词、边界折回理论和部分 Subject 字段，但记忆破碎，无法确认自己在组织中的角色。Venn 的恐惧来自两个方向：他害怕自己是受害者，也害怕自己曾是帮凶。

在剧情中，Venn 不应过早成为完整真相发布者。他的作用是提供破碎但关键的理论线索，并让玩家感到：组织造成的伤害不只留在设施里，也留在人的记忆结构中。

## Orin 与组织的关系边界（解锁4）

Orin 不是 Project ECHO 的核心研究员，也不是建设期的维护人员。他更适合作为事故后旧门禁和灯塔下层的接触者。他不知道完整组织目标，但知道灯塔下层、旧钥匙、外来者标记和大震夜事故之间有关。

他的责任不在于设计 Project ECHO，而在于他年轻时打开或未能阻止别人打开事故后残留的外层门，导致有人失踪。此后他留在灯塔，既是阻止别人接近危险，也是惩罚自己继续守着旧罪。

Orin 可以知道很多入口和后果，但不应像 Lab Terminal 一样解释完整技术。他的语言应带罪疚、回避和警告。

## 组织与岛民的伤害关系（解锁4）

赫利俄斯结社对归潮岛造成的伤害不只是一次爆炸。它改变了岛民的生活结构：出海变危险，村民长期失踪，回声病增加，孩子被禁止进入雾林，灯塔成为恐惧象征，潮民禁忌被外来者嘲笑后又被灾难证明。

组织对岛民的伤害有三层：

- 物理伤害：地震、坍塌、失踪和设施污染。
- 记忆伤害：失忆、幻听、重复梦境和身份混乱。
- 社会伤害：村民互相隐瞒、害怕外来者、无法相信外界承诺。

因此，终局即使解除归潮，也无法立刻修复这些伤害。

## 关键实验前的内部冲突（解锁5）

关键实验前，Project ECHO 内部已经出现冲突。晶体共振组报告核心响应不稳定，工程维护组报告灯塔节点反馈异常，人体保护组要求降低暴露强度，安保与高层则要求推进全岛级覆盖验证。

主人公父亲试图延迟高功率激活，母亲试图提高 Subject 07 的保护优先级，但组织高层认为实验窗口难得，归潮岛的异常条件不可复制。

事故不是一次意外误操作，而是高层野心、科学傲慢、伦理退让和系统风险累积后的爆发。

## 关键实验事故与组织崩溃（解锁5）

关键实验中，主共振核心进入失控高频响应，灯塔节点同步过载，雾林边界产生异常回声，人体观测区出现大规模神经反应异常，低温休眠系统启动紧急隔离。

设施内多部门互相抢夺权限：安保试图封锁数据，工程维护组试图切断节点，人体保护组试图保护 Subject，晶体共振组试图降频。权限冲突导致关键流程互相阻塞。

最终爆炸、地震和设施坍塌造成岛内赫利俄斯结社主要人员死亡或失踪。Project ECHO 在岛上的组织结构崩溃，但它留下的系统继续运行，成为归潮场。

## 事故后的档案销毁与残缺记录（解锁5）

大震夜前后，安保与保密组试图销毁部分人员名单、人体观测记录和核心实验日志。事故导致销毁不完整，一部分纸质记录被烧毁，一部分终端索引损坏，一部分被海水或潮气破坏。

因此，玩家后期获得的信息总是碎片化的：Project ECHO 人员名单残页、实验日志碎片、安全弹射记录残页、父母权限覆盖卡、Lab Terminal 残缺字段。

这种残缺不是单纯为了悬疑，而是组织保密、事故损坏和时间侵蚀共同造成的结果。

## 事故后组织残余（解锁5）

大震夜后，赫利俄斯结社在归潮岛上的主要人员死亡、失踪或被设施封闭。岛上没有稳定运转的组织分部，只剩残缺终端、自动系统、旧门禁和部分仍在运作的核心设备。

岛外是否存在残余分支，不应在早中期明确。终局可以留下有限伏笔：外界某些旧频段偶尔仍试图呼叫 Project ECHO；Lab Terminal 中可能存在未发送完成的数据包；人员名单残页显示某些高层并未登岛。

这让后续扩展有空间，但不应削弱本作主线：归潮岛的核心冲突是玩家、岛民和遗留系统，而不是立刻变成追捕外部反派。

## 终局后外界是否会注意归潮岛（解锁5）

如果玩家关闭或部分关闭归潮场，归潮岛可能重新出现在外界航线、无线电和地图中。外界注意到归潮岛的方式取决于结局：

- 关闭归潮场：外界船只和信号可能恢复，调查者、媒体、政府或组织残余都有可能注意到岛。
- 稳定归潮场：外界仍难以进入，但异常信号可能变弱，岛民病症可能缓解。
- 部分关闭：有限通道可能让少数人离开，也可能让外界断续捕捉到岛的位置。
- 放弃操作：岛仍被归潮保护和囚禁，外界难以确认位置。

外界重新注意归潮岛不是纯粹好事。它可能带来自由、医疗和真相调查，也可能带来审判、掠夺、组织残余和新的控制。

## 组织作为反派的使用原则（解锁4）

赫利俄斯结社不应只是“坏组织名字”。它应体现为一套持续影响世界的结构：伪装、记录、门禁、实验语言、损坏设施、伦理退让、余波和幸存者的沉默。

对话中不要让所有 NPC 都直接骂组织。不同角色应从自己的位置理解它：

- Orin：把它看作自己曾经帮忙打开的门。
- Venn：把它看作记忆里的空洞和可能的罪责。
- Lab Terminal：把它显示为权限、部门、记录和错误码。
- Mara：把它理解为外来者破坏蓝脉禁忌。
- Lira：把它理解为把人体痛苦写成实验数据的体系。

组织的恐怖感来自它把伤害变成流程，把人变成字段，把岛变成试验场。

## 内部语言：把伤害写成流程（解锁4）

赫利俄斯结社的档案语言应保持冷静、技术化，甚至故意避开“人”的词。村民不是村民，而是“地表人口”；病人不是病人，而是“暴露反应样本”；失踪不是失踪，而是“边界回收失败”；恐惧不是恐惧，而是“行为阻抗”。

这种语言可以出现在实验日志、终端字段、人员名单残页和被涂黑的备忘录中。它能让玩家感到组织最可怕的地方不是粗暴残忍，而是把残忍处理得像普通文书。

示例字段：

```text
SURFACE POPULATION RESPONSE: manageable
MEMORY DISPLACEMENT: within projected tolerance
SUBJECT DISTRESS: non-critical
LOCAL TABOO INTERFERENCE: cultural noise
```

Lira 后期看到这类字段时会愤怒，因为她习惯记录症状，却不会把痛苦从人身上剥离。Mara 会说外来者连罪都不肯用人的话说。

## 伦理审查缺失记录（解锁5）

Project ECHO 的伦理审查记录不是完整保存的文件，而是一组缺失、跳号和被覆盖的字段。Lab Terminal 可以显示“伦理审查记录缺失”，但不能告诉玩家这是否因为事故损坏、安保销毁，还是项目根本没有认真审查。

残缺记录可包含以下信息：人体保护组曾多次提交降低暴露强度的建议；人体观测组要求扩大样本量；安保与高层以“实验窗口不可复制”为由压过反对意见。

这类记录应让玩家理解：灾难不是某个疯狂科学家突然失控，而是一套制度不断把“不该继续”改写成“继续但附带保护措施”。父母的责任也在这里变得复杂：他们提出保护，并没有阻止系统利用保护继续前进。

## 人体保护组的内部争论（解锁5）

人体保护组内部并非铁板一块。有些成员认为只要保护仓、低温休眠和神经稳定剂足够完善，就可以继续观察；另一些成员认为保护机制正在被组织当成扩大实验的许可。

主人公母亲处在这种争论中央。她相信保护技术能减少伤害，但事故前已经意识到：只要 Subject 体系继续存在，保护就会被写进实验条件，而不是成为停止实验的理由。

可以通过残缺备忘录表现这层冲突：

```text
保护仓不是授权暴露的理由。
Subject 字段不可替代监护同意。
紧急弹射权限需脱离安保组复核。
```

这些内容只应在终局或高解锁阶段出现，用于加深父母责任，而不是提前洗白。

## 晶体共振组的模型误判（解锁5）

晶体共振组的核心错误是把蓝脉当成可被完全建模的材料。他们把潮汐、雾林边界、灯塔节点、人体神经反馈分别建模，却低估了它们在全岛尺度下互相放大的效果。

事故前，纸带记录和工程备忘录中已经出现异常峰值，但被解释为“可控偏差”。父亲曾主张延迟全功率激活，却仍然参与了校准流程。这使他的责任无法被一句“他曾反对”抵消。

终局可以让玩家看到几份互相矛盾的记录：一份说模型安全，一份标注异常，一份被手写警告覆盖。冲击来自玩家发现灾难其实有预兆，只是预兆被系统吞掉了。

## 安保组的村民管控手段（解锁4）

安保与保密组对潮民的控制不一定总是暴力。他们更常使用物资依赖、医疗承诺、伪装解释和谣言稀释。

常见手段包括：把失踪者解释为海难；把回声病解释为地方性癔症；把灯塔蓝光解释为无线电测试；向合作村民提供药物和工具；把反对者描述为阻碍救援和进步的守旧者。

这解释了为什么村里对外来者的记忆并不统一。有人记得药，有人记得灾难，有人记得承诺，有人记得沉默。组织留下的伤害因此不只是设施，还有村民之间难以修复的不信任。

## Project ECHO 撤离失败（解锁5）

关键实验事故后，赫利俄斯结社并没有成功撤离。归潮场过早形成，灯塔节点过载，地下通道坍塌，海上补给路线失效。部分人员试图通过地下轨道和灯塔维护通道离开，但被封闭场和设施损坏困住。

安保组试图销毁档案并发送数据包，但无线电和外部链路在归潮场中不断回折。Lab Terminal 后期可恢复未发送完成的数据包字段，暗示组织有些真相没有离开岛。

这能强化终局：玩家面对的不只是旧记录，而是一场连罪证都没能成功逃走的崩溃。

## 岛外残余的使用边界（解锁5）

岛外残余可以作为结局后的压力，但不应抢走本作主线。玩家在主线中解决的是归潮岛的遗留系统、父母责任和岛民未来，而不是追杀所有赫利俄斯结社成员。

可用伏笔包括：未发送数据包、远方旧频段呼叫、人员名单中未登岛高层、外界对蓝脉资源重新产生兴趣。不可用做法是让终局突然出现外部反派替玩家承担所有道德压力。

外部残余应让结局更复杂：关闭归潮场带来自由，也可能重新暴露岛屿；稳定归潮场保留保护，也保留囚禁。

## 组织真相的揭示方式（解锁5）

组织真相不应由一段完整说明一次性讲完，而应由不同证据拼合：

- 灯塔日志证明地表节点异常。
- 雾林石碑和祭歌证明潮民早已知道边界风险。
- 草药屋病历证明人体影响长期存在。
- 人员名单残页证明部门和权限结构。
- 实验日志碎片证明人体观测和核心过载。
- 父母录音证明责任与保护动机并存。
- Lab Terminal 证明字段事实，但不负责道德结论。

玩家真正受到冲击的时刻，不是第一次听见“赫利俄斯结社”，而是发现每个看似零散的生活细节都曾被组织纳入流程。
