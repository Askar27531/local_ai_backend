# 08 道具与线索

> 本文件是《归潮之岛》的线索系统主干。每个道具都应连接地点、NPC、剧情阶段和玩家可追问的问题。道具不是单纯收集物，而是玩家拿去询问 NPC、打开新地点、拼合真相的证据。

## 破损金属铭牌：早期可见信息（解锁1）

地点：漂流海滩，玩家醒来时随身携带。

可见描述：一枚被海水腐蚀的金属铭牌，边缘烧蚀，背面有断裂挂孔。铭牌上只能看清几行残缺文字：

```text
Project ECHO
一串残缺编号
```

玩家初始理解：这可能是某种身份牌、货物标签或外来者遗留物。玩家不知道文字含义。

NPC 初次反应：Karo 不认识这些字，只觉得这东西不像岛民物品；Lira 认为材质和工艺不像村里能制造；Orin 似乎见过类似标记，但会回避；Nia 觉得它像从海里捡来的铁片；Venn 听到 Project ECHO 时会头痛或迟疑。

限制：早期任何 NPC 都不能根据铭牌确认玩家身份。普通 NPC 不能解释旧编号。

## 破损金属铭牌：后期真相（解锁5）

后期可确认，破损金属铭牌证明玩家与 Project ECHO 有直接关系。Subject 07 不是名字，而是实验编号。铭牌关联保护仓记录、低温状态、安全弹射和父母权限覆盖。

可解释 NPC：Lab Terminal 可以通过权限和实验记录确认；Venn 可产生残缺记忆；Orin 可承认自己见过类似编号，但不应一次性说明全部真相。

限制：该信息只能在玩家进入地下设施、读取实验日志、获得保护仓相关碎片或访问 Lab Terminal 后确认。

## 失效指南针：早期可见信息（解锁1）

地点：漂流海滩残骸附近。

可见描述：旧式指南针外壳进水，玻璃有裂纹，指针无法稳定指北，有时缓慢旋转，有时突然停住。

NPC 初次反应：Karo 会说在归潮岛上相信指南针是愚蠢的；Venn 可能说方向本身出了问题；Lira 会关心玩家接触指南针时是否头痛；普通村民不会解释为水晶或装置影响。

用途：引导玩家询问海上边界、村口码头、雾林、灯塔蓝光和归潮现象。

## 失效指南针：后期解释（解锁4）

后期可以确认，指南针异常与地下蓝脉、灯塔节点、雾林边界和残留共振场有关。靠近蓝色水晶碎片、雾林石碑、灯塔下层或地下设施时，指针旋转会更剧烈。

可解释 NPC：Venn 可提出封闭场猜测；Orin 可承认灯塔和方向异常有关；Lab Terminal 可显示 `RESONANCE FIELD` 片段。

限制：不能在早期由 Karo 或 Nia 解释为科学机制。

## 湿透的航海笔记残页（解锁1）

地点：漂流海滩，夹在木板和海草之间。

可见描述：残页被海水泡软，只能看清几句：“第三次离开失败”“雾不是天气”“灯塔亮起时，海会折回来”“不要相信罗盘”。

用途：引导玩家怀疑归潮不是普通迷航。玩家可以拿它询问 Karo、Venn 或 Orin。

NPC 反应：Karo 会警觉，因为残页内容接近他的离岛经历；Venn 会把它当作边界证据；Orin 不会直接解释灯塔含义。

限制：残页不能直接说明 Project ECHO、地下设施或玩家身份。

## Karo 的受潮航海本（解锁2）

地点：村口码头旧船舱，或 Karo 私藏的防水布包里。

可见描述：一本被海水泡皱的航海本，里面写着风向、潮位、失败日期、罗盘异常和灯塔蓝光出现的夜晚。部分页面只剩盐痕和模糊墨迹。

用途：证明 Karo 的恐惧来自反复记录，而不是单纯迷信。玩家可用它追问离岛失败、海上边界、灯塔蓝光和无线电噪声。

NPC 反应：Karo 不愿轻易承认这本本子存在；Venn 会认为它是归潮边界的经验数据；Lira 会把它和 Karo 的头痛、失眠联系起来。

限制：航海本不能解释地下技术，只能提供规律和亲历证据。

## 磁化船钉（解锁2）

地点：村口码头旧船、码头仓库或 Karo 工具箱。

可见描述：普通船钉会轻微吸住小铁片，靠近失效指南针时能让指针更加不稳。钉身有盐蚀和蓝灰色细粉。

用途：把码头、海上边界、罗盘异常和灯塔蓝光联系起来。它让玩家意识到归潮会影响物体，而不只是影响人的方向感。

NPC 反应：Karo 会说这些钉子在大雾之后才变怪；Venn 会推测它们长期接触异常场；Lira 不会解释磁性，但会记录玩家接触后的头痛反应。

限制：普通 NPC 不能说明完整水晶共振原理。

## 旧无线电录音（解锁2）

地点：村口码头仓库、Karo 旧船或 Venn 废屋。

可见描述：一段录在旧磁带或纸带上的无线电噪声，包含重复低语、断续呼号和灯塔蓝光夜的刺耳干扰。播放时偶尔像是在重复听者曾说过的话。

用途：连接海雾、无线电失效、井边回声和记忆残留。玩家可拿它询问 Karo、Venn、Lira 或 Orin。

NPC 反应：Karo 讨厌这段声音；Venn 会反复听并记录时间；Lira 会提醒玩家不要长时间播放；Orin 会警告玩家别把噪声当成答案。

限制：录音不能直接证明 Project ECHO，只能作为异常信号证据。

## 蓝色水晶碎片：早期可见信息（解锁2）

地点：雾林边缘、地下通风口附近或 Nia 藏物处。

可见描述：小块蓝色半透明石头，普通状态下只发出极弱蓝光。靠近时可能引发耳鸣、头痛或短暂熟悉感。

NPC 初次反应：Nia 觉得漂亮，但大人不让碰；Lira 认为它可能导致头痛和梦境异常；Karo 不愿靠近；Mara 会警告玩家不要把它带离原处。

用途：引出蓝脉禁忌、回声病和雾林异常。

限制：早期不能解释为地下核心材料。

## 蓝色水晶碎片：后期解释（解锁4）

后期可以确认，蓝色碎片来自地下蓝脉矿脉。它能传导和放大特定频率的能量，并与灯塔、雾林边界和地下装置产生弱共振。

可解释 NPC：Venn 可将其与磁场和人体感知联系起来；Orin 可承认灯塔蓝光与蓝脉有关；Lab Terminal 可显示样本编号或频率记录。

限制：该信息不应由 Karo、Nia 或普通村民科学解释。

## Nia 的蓝色小石头（解锁1）

地点：Nia 的口袋、小布包或井边藏物处。

可见描述：一颗比指甲略大的蓝色小石头，夜里会微微发亮。Nia 把它当成漂亮玩具，称它像“海里掉下来的星星”。

用途：低剧透地引出蓝色水晶的危险、井边回声和 Mara 的禁忌。玩家如果温和提醒，Nia 可能交出石头；如果强硬追问，她会害怕。

NPC 反应：Lira 会建议立刻收走并观察 Nia 是否头痛；Mara 会严厉警告不能把蓝脉石带回家；Nia 不理解科学危险。

限制：Nia 不能解释水晶矿脉或地下设施。

## Lira 的样本瓶（解锁2）

地点：草药屋样本柜。

可见描述：几个贴着手写标签的玻璃瓶，装有雾林蓝色苔藓、异常叶片、井边水样和被布包住的蓝色碎片。

用途：把雾林植物、蓝色水晶、回声病症状和玩家身体反应联系起来。玩家可据此追问 Lira 为什么要记录梦境和头痛时间。

NPC 反应：Lira 会谨慎说明样本与症状可能有关，但不能当成完整证据；Venn 会对样本瓶标签中的日期感兴趣；Mara 会提醒不要把蓝脉当成普通样本。

限制：样本瓶不能直接证明人体实验。

## 回声病病历：早期病症记录（解锁1）

地点：草药屋。

可见描述：Lira 手写病历，记录村民出现失忆、耳鸣、重复梦境、方向错乱和短暂幻听的案例。

用途：证明岛上长期存在类似症状，让玩家的失忆不再像孤立事件。Lira 可以根据病历判断玩家症状与回声病相似。

限制：病历只证明症状规律，不能直接证明实验或玩家身份。

## Lira 继承的旧病历夹（解锁3）

地点：草药屋锁柜。

可见描述：一本由草药屋代代保存的旧病历夹，纸页边缘变黄。最早几页来自大震夜后的前代草药师，后续页由 Lira 的母亲整理，记录伤者和回声病患者的头痛、幻听、失忆和“地下敲墙声”描述。

用途：连接 Lira、草药屋三代病历、大震夜伤者和地下异常传闻。玩家可用它追问 Lira 为什么不愿公开这些记录。

NPC 反应：Lira 会承认母亲那一代人记录过更严重的回声病；Venn 会对日期和描述产生不安；Orin 可能听到“地下敲墙声”后沉默。

限制：病历夹不能说明 Project ECHO 完整计划。

## 雾林风铃碎片（解锁1）

地点：雾林边缘，挂在树枝和石碑路径之间。

可见描述：由贝壳、细金属片和旧线绳做成的风铃碎片。风起时声音细碎，海雾浓时声音会变得不自然地重复。

用途：连接潮民传统、雾林边界、蓝脉禁忌和声音异常。玩家可询问 Mara、Nia 或 Venn。

NPC 反应：Mara 会说风铃不是装饰，而是判断边界和蓝脉醒来的东西；Nia 会说孩子不能乱碰；Venn 会怀疑重复声音与回声现象有关。

限制：不能直接解释地下通风口或设施结构。

## 雾林石碑拓片（解锁3）

地点：雾林三块石碑。

可见描述：三块石碑图案组合后形成闭合环形符号。拓片上有潮民纹样，也有不像手工雕刻的精确线条。

用途：连接 Mara 的祭歌、Orin 的灯塔旧钥匙、Venn 的边界理论和灯塔下层入口。

NPC 反应：Mara 认为石碑是蓝脉边界；Orin 认为图案与灯塔下层入口有关；Venn 会把闭合环形符号与归潮边界联系起来。

限制：拓片不能直接打开核心区域，也不能说明完整设施结构。

## Mara 的祭歌木片（解锁3）

地点：长老屋。

可见描述：几片刻有旧词的薄木片，表面用贝壳粉和蓝灰颜料描线。词句提到“三块石头围住蓝骨”“铁塔刺进山腹”“海水倒着走”。

用途：把雾林石碑、蓝脉禁忌、大震夜和灯塔联系起来。玩家可用它询问 Mara 或对照雾林拓片。

NPC 反应：Mara 不会把它当作密码，而会强调这是记住灾难的方法；Venn 会觉得祭歌和边界结构有对应关系；Orin 会避免评价祭歌里的“铁塔”。

限制：祭歌木片不能给出科学细节。

## 地下通风口金属铭片（解锁3）

地点：雾林深处，被藤蔓和湿土盖住的通风口附近。

可见描述：一块锈蚀金属铭片，字迹残缺，只能看见编号、箭头和部分外来者标记。铭片材质明显不是潮民手工制品。

用途：中期证明雾林下方存在人工结构，连接雾林、灯塔下层和旧设施入口。

NPC 反应：Orin 会警告玩家不要继续挖；Venn 会试图把编号和旧地图对照；Mara 会说外来者把铁插进岛的骨里；Lira 只能从植物异常角度判断。

限制：铭片不能直接说明 Project ECHO 全貌或核心位置。

## 灯塔看守日志（解锁2）

地点：废弃灯塔地表灯室或旧值班桌。

可见描述：一本发霉的日志，前半部分像普通天气和灯火记录，后半部分出现蓝光、夜间震动、门禁异常和“不要下去”的断句。

用途：连接 Orin、灯塔蓝光、大震夜遗留系统和灯塔下层入口。玩家可用它追问 Orin 为什么守着灯塔。

NPC 反应：Karo 会说灯塔亮的时候海最危险；Orin 会明显不悦；Venn 会把日志日期和大震夜前后变化联系起来；Mara 会认为日志证明外来者破坏了禁忌。

限制：日志不能直接解释控制节点或地下设施全貌。

## 灯塔旧钥匙（解锁3）

地点：Orin 持有。

可见描述：一把沉重旧钥匙，齿形不像普通门锁，钥匙柄有被烧过的痕迹和蓝灰色残留。

用途：打开灯塔下层入口外门，但不能直接打开地下设施核心。它是 Orin 判断玩家是否准备好的信任节点。

NPC 反应：Orin 只有在玩家提供足够线索后才可能交出钥匙；Mara 会提醒钥匙不是许可；Venn 会对钥匙齿形产生熟悉感。

限制：玩家直接追问 Project ECHO 不应获得钥匙。

## Orin 的旧门禁牌（解锁4）

地点：灯塔下层入口、Orin 私藏物或旧控制台旁。

可见描述：一块磨损门禁牌，边缘烧焦，表面有外来者标记、残缺权限编号和无法完整读取的姓名或代号。

用途：让 Orin 无法完全否认自己与旧设施有关。它连接灯塔下层、旧门禁、Project ECHO 标记和事故后残留的守门罪疚。

NPC 反应：Orin 会沉默或警告玩家不要把门禁牌当成答案；Venn 可能见过类似编号；Lab Terminal 后期可读取部分权限痕迹。

限制：门禁牌不能直接确认玩家身份或父母记录。

## Orin 的烧焦钥匙环（解锁4）

地点：Orin 身边，或灯塔旧抽屉。

可见描述：一个烧焦变形的钥匙环，上面原本挂过不止一把钥匙，剩下的金属边缘有高温痕迹。

用途：连接 Orin、灯塔蓝光夜、失踪者和他作为守门人的赎罪动机。玩家可用它追问“那晚你打开过什么门”。

NPC 反应：Orin 不愿谈；Mara 可能说守门人也被门困住；Venn 会把钥匙环和门禁记忆联系起来。

限制：钥匙环是人物动机证据，不是直接开门道具。

## Venn 涂黑的研究页（解锁3）

地点：Venn 废屋。

可见描述：多页被涂黑、撕裂又重新粘起的研究纸。能看见“边界”“回声”“Subject”“ECHO”“坐标折回”等残词。

用途：连接 Venn、Project ECHO、失忆和自我防备。玩家可以用它追问 Venn 为什么破坏自己的笔记。

NPC 反应：Venn 会说也许是他自己不想想起来；Lira 会担心这会刺激他的症状；Orin 会警惕玩家过早相信涂黑内容。

限制：研究页不能独立确认旧编号或终局真相。

## Venn 的碎纸地图（解锁2）

地点：Venn 废屋墙面和地面。

可见描述：许多潮湿地图碎片，上面画着海岸、雾林、灯塔和村口码头。多条路线最后都被画回同一个圆。

用途：帮助玩家理解归潮不是普通迷路，而像边界折回。可与失效指南针、航海残页、雾林石碑拓片互相印证。

NPC 反应：Venn 会用地图解释自己的怀疑；Karo 觉得纸上画不出海的坏脾气；Lira 会注意地图旁边的症状记录。

限制：地图不能解释完整装置。

## Karo 写给亡妻的旧信（解锁2）

地点：Karo 船舱、旧木盒或码头仓库。

可见描述：一封没有寄出的信，纸页受潮，内容提到他曾答应带妻子离开岛，却在一次海雾之后失去一整天记忆。

用途：体现 Karo 为什么害怕海雾，也让玩家理解他的冷硬不是单纯脾气差。玩家可用它触发 Karo 更柔软的回答。

NPC 反应：Karo 会愤怒或沉默，之后可能承认他不是不想离开，而是不敢再让别人跟着他试。

限制：旧信只揭示人物创伤，不揭示技术真相。

## Mara 的贝壳护符（解锁1）

地点：长老屋、Nia 身上或雾林边界。

可见描述：用贝壳、细线和蓝灰色小石粉做成的护符。Mara 会把它给孩子或即将进入雾林的人。

用途：连接 Mara、Nia、蓝脉边界和潮民保护传统。玩家可用它询问禁忌为什么不是普通迷信。

NPC 反应：Mara 会说护符不是魔法，而是提醒人不要忘记规则；Nia 会觉得戴上它就不会被雾带走；Venn 会认为护符图案和石碑纹样相似。

限制：护符不能阻止归潮，只是文化与记忆线索。

## 井边潮湿纸卷（解锁2）

地点：静潮村水井石缝，需要通过井边回声谜题获得。

## 旧无线电录音：播放异常（解锁2）

播放录音时，玩家听到的不应是完整语音，而是几层声音叠在一起：海浪底噪、短波噪声、断续呼号和像熟人低语的残响。偶尔会出现一句听不清来源的话：“回到原点。”

Karo 听到录音会立刻关掉机器；Lira 会要求玩家记录播放后的头痛和耳鸣；Venn 会想反复播放并标注时间；Nia 会觉得录音“在学人说话”；Orin 会警告玩家别把噪声当指路。

录音适合触发低剧透问题：为什么无线电不稳定、为什么海雾里有声音、为什么 Karo 害怕出海。它不适合直接触发终局解释。

## 灯塔看守日志：可读页（解锁2）

灯塔看守日志可读页应像普通值班记录逐渐失控：

```text
晴，灯室玻璃破损，未点灯。
雾。夜半蓝光自下层缝隙透出。
门禁自响三次，无人靠近。
海面倒流，码头方向有呼喊。
不要下去。不要让孩子靠近。
```

玩家可用这页追问 Orin 为什么守塔，也可拿给 Karo 询问灯塔蓝光与海雾。Orin 的回答应承认危险存在，但仍避免解释地下设施全貌。

这页日志的作用是“证明灯塔异常长期存在”，而不是把灯塔直接定义为控制节点。

## Venn 涂黑的研究页：残留词组（解锁3）

涂黑研究页上可以保留以下词组：

```text
边界不是线，是回声。
地图回到原点，人也会吗？
ECHO 字段出现于三份残录。
Subject 字段不等于姓名。
不要相信第一次想起来的记忆。
```

这些词组能强化 Venn 的破碎感：他并不是百科式知情者，而是在防止自己被错误记忆牵引。玩家拿研究页追问时，Venn 可以解释“涂黑不是隐瞒你，是我不相信我自己”。

限制：研究页不应单独确认旧编号。它只能把玩家推向终端、地下舱体接口片和更深设施。

## 父母录音带：残缺播放片段（解锁5）

录音带播放时可以包含噪声、警报和断句：

```text
如果你听见这段……说明保护流程至少启动过。
不要让权限系统替他决定。
Subject 07 不是资产。
我们来不及把一切改正，但至少要把他送出去。
如果他醒来，不要只把真相交给机器。
```

这段录音应承担情感重量，但不能单独洗白父母。玩家需要同时看到人员名单、实验日志、安全弹射记录和主共振核心状态，才能理解父母既参与过错误，也在事故中试图保护玩家。

地表 NPC 更适合回应“听完后的代价”，而不是解释录音技术。Lira 会关心玩家是否还能承受；Mara 会提醒爱不能抵消伤害；Venn 会提醒玩家不要把父母的选择当成自己的命令。

## 主共振核心频率纸带：终局核验片段（解锁5）

纸带上的曲线不是普通密码，而是主共振核心失稳的证据。玩家检查时可以看到几个标记：

```text
SURFACE NODE FEEDBACK
CORE DRIFT
ECHO CHIP RESPONSE
MANUAL STABILIZE POSSIBLE
FULL SHUTDOWN RISK: STRUCTURAL SHOCK
```

Lab Terminal 可根据纸带恢复部分流程，但仍应保持残缺。Venn 可以解释风险，但必须承认自己不是可靠执行者。Orin 可以从灯塔节点角度说明：地表节点只是反应链的一部分，不是全部。

限制：纸带不能变成“按步骤通关攻略”。它提供选择依据，而不是替玩家作选择。
