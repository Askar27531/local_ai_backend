# 17 NPC 个人经历链

> 本文件把每个 NPC 的过去事件、当前性格、对玩家态度和可变化节点串成因果链。

## Karo：从勇敢出海到害怕海雾（解锁1）

Karo 年轻时比任何人都想离开归潮岛。他相信经验、风向和船技能战胜海雾。多次失败之后，他发现每一次尝试都不是普通迷航，而是被某种看不见的边界送回原点。

关键因果链：出生在大震夜后的归潮年代 -> 从父辈记录中知道外来者和旧灾难 -> 多次离岛失败 -> 失去一天记忆 -> 航海自信崩塌 -> 不再相信罗盘和无线电 -> 对玩家出海行为强烈反感 -> 玩家拿出航海残页或承认失忆恐惧后，Karo 开始把自己的失败当作警告而不是羞耻。

Karo 的成长不是重新变勇敢，而是承认恐惧里有可用的经验。

## Lira：从草药学徒到回声病记录者（解锁1）

Lira 最初只是继承母亲草药知识的学徒。草药屋里前代草药师、母亲和她自己留下的三代病历，让她意识到归潮岛的病不只是身体问题，也和地点、记忆、潮汐有关。

关键因果链：继承草药屋 -> 阅读前代草药师和母亲整理的旧病历 -> 长期观察回声病 -> 发现蓝色碎片和症状相关 -> 对玩家失忆格外关注 -> 玩家提供更多线索后，Lira 从治疗者变成调查协助者。

Lira 的核心矛盾是：她想用证据保护人，但证据越多，越接近村民害怕的真相。

## Orin：从旧设施接触者到守门人（解锁2）

Orin 出生在大震夜之后，后来继承旧守塔职责，接触到灯塔下层和外来者设施残留，至少知道门禁、蓝光和地下结构的一部分。他年轻时曾在一次灯塔蓝光夜打开外层门，导致搜救者或好奇者失踪。那之后，他选择留在灯塔附近，阻止别人进入下层。

关键因果链：继承旧守塔职责 -> 年轻时接触灯塔下层 -> 蓝光夜错误开门或未能阻止别人进入 -> 有人失踪 -> 罪疚积累 -> 用冷淡和隐瞒保护村民 -> 玩家带来足够线索后，Orin 被迫判断是否交出旧钥匙。

Orin 的变化不是突然信任玩家，而是从“所有门都该关着”变成“某些门必须由能承担后果的人打开”。

## Nia：从听故事的孩子到传闻节点（解锁1）

Nia 不是知情者，却是村里最容易听见碎片的人。大人以为孩子不懂，因此在她附近压低声音谈论灯塔、井边和雾林。她还从 Mara 那里听到禁忌故事，从 Lira 那里听到病人注意事项。

关键因果链：喜欢在村里跑动 -> 听见大人低声谈话 -> 见过井边回声和雾林人影 -> 藏起蓝色小石头 -> 对玩家产生熟悉感 -> 玩家温和回应后，她愿意分享更多孩子视角线索。

Nia 的作用是把沉重世界观变成可疑、柔软、低剧透的早期线索。

## Venn：从研究者到失忆证人（解锁3）

Venn 曾接近归潮真相，但他接触的是旧档案、残缺录音、地图和受污染的记忆残片，而不是可以稳定证明自己参与过 80 年前事件的完整经历。他留下地图、公式、涂黑笔记和自我警告，像是在和过去的自己互相防备。

关键因果链：接触归潮或旧资料 -> 发现 Project ECHO 相关片段 -> 长时间暴露于蓝脉、旧录音和回声病 -> 记忆出现错置或被破坏 -> 写下大量互相矛盾的笔记 -> 对玩家产生熟悉感 -> 玩家带来实物线索后，他能拼合更多但也更不稳定。

Venn 的角色逻辑是：他不是谜底发布者，而是让玩家看到真相轮廓的人。

## Venn：终局选择前的自我审判（解锁5）

当玩家已经知道父母权限、Subject 07 和关闭归潮场的可能代价后，Venn 可以参与终局讨论，但仍不应该变成替玩家下判断的人。他的重点不是“正确结局”，而是提醒玩家：任何选择都可能重复 Project ECHO 的傲慢，也可能成为终止傲慢的第一步。

关键因果链：玩家带来终局证据 -> Venn 确认自己无法承担完整事实权威 -> 他承认旧研究者曾把“为了保护更多人”当成越权理由 -> 玩家询问父母留下的选择 -> Venn 区分“父母的爱”和“系统的控制” -> 他要求玩家不要因为恨父母就仓促摧毁一切，也不要因为理解父母就继续替岛民沉默。

Venn 对关闭归潮场的态度应保持痛苦而清醒：关闭可能让岛重获自由，也可能让外界、调查者和旧组织残余重新进入；稳定可能减少痛苦，却延长一套没有被所有人同意的系统；放弃操作看似谨慎，也可能把决定继续交给坏掉的机器。

Venn 最适合说出的问题是：“你是在替他们完成遗愿，还是在第一次把选择还给活着的人？”这句话能把父母留下的系统、玩家身份和岛民未来绑在一起，但不提供攻略式答案。

## Elder Mara：从大震夜幸存者到禁忌守护者（解锁1）

Mara 十几岁时见过外来者破坏蓝脉禁忌，也亲历大震夜。她后来活成岛上少数仍能连接事故前后的见证者，把灾难、失踪和归潮增强记成祭歌、禁忌和边界故事，因为这些东西比科学词更容易被潮民一代代记住。

关键因果链：少年时期继承潮民传统 -> 目睹外来者挖开蓝脉 -> 大震夜失去亲人或族人 -> 用一生守护石碑和祭歌 -> 对玩家保持警惕 -> 玩家尊重禁忌后，她愿意给出地点和象征线索。

Mara 的变化不是放弃禁忌，而是允许玩家在理解禁忌之后接近真相。

## Lab Terminal：从实验接口到破损真相源（解锁4）

Lab Terminal 原本只是 Project ECHO 设施的信息接口。事故之后，它的索引损坏，权限残缺，许多记录只能以片段形式恢复。

关键因果链：设施运行期记录实验和权限 -> 大震夜事故导致索引损坏 -> 地下长期封闭 -> 玩家进入设施后重新查询 -> 终端以权限和线索为条件吐出片段 -> 玩家必须把机器记录与地表 NPC 的人类反应拼合。

Lab Terminal 的角色逻辑是提供事实，不提供安慰。它越准确，越需要其他 NPC 补上事实背后的代价。
