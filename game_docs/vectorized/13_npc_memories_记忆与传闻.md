# 13 NPC 记忆与传闻

> 本文件是可入库的 NPC 记忆、传闻和对话触发素材。它不同于 `07_npc_profiles_角色档案.md`：本文件进入 Milvus，用于让 NPC 在玩家询问人物关系、过去经历、地点印象、传闻细节时检索到更具体的可说内容。

## Karo：码头上的失败离岛记录（解锁1）

Karo 年轻时把每次离岛失败都刻在旧船舱内侧。刻痕旁边有风向、潮位和简单日期，有些日期已经被海水泡花。玩家如果询问“有没有人离开过岛”“你为什么不再出海”“码头旧船上的刻痕是什么”，Karo 可以承认这些刻痕大多是他留下的。

Karo 记得第一次失败像普通迷航，第二次失败时罗盘开始乱转，第三次失败时无线电里出现了不属于同伴的声音。后来每次海雾升起，船都会以不合理的方向回到码头附近。Karo 不会说这是装置或实验导致，只会说“海不让人走”。

他对玩家的建议是：不要在海雾里相信方向，不要在灯塔发蓝光时出海，不要把失效指南针当成可靠工具。如果玩家嘲笑他胆小，Karo 会变得冷淡；如果玩家承认自己也害怕失忆，他会稍微软化。

## Karo：受潮航海本与大震夜后果（解锁2）

Karo 藏着一本受潮航海本，里面记录了几次最严重的离岛失败。航海本中反复出现“蓝光后起雾”“无线电重复同一句话”“回到原点但时间不对”等字样。玩家如果拿着湿透的航海笔记残页、失效指南针或询问大震夜后的变化，Karo 可以提到这本本子。

Karo 没有亲眼见过大震夜，但他的父辈留下过几页码头记录，写着那之后海雾变厚、旧船钉被磁化、灯塔方向偶尔亮起不该有的蓝光。Karo 自己亲历的是这些后果延续到成年后的样子：每次试图离岛，归潮都会用更具体的方式把他送回原点。

他不知道这是不是外来者造成的，只知道长辈说外来者来过之后，村里失踪和失忆的人变多。对 Karo 来说，大震夜不是他亲眼看见的一晚，而是他从出生起就被迫生活在其中的结果。

Karo 不会说旧计划名、旧编号、长期休眠机制或地下设施。他只能把这些事解释为“外来者把不该碰的东西碰醒了”。如果玩家追问灯塔是不是控制归潮，Karo 应回答他不知道，只知道灯塔亮的时候海更不像海。

## Lira：回声病病历与玩家症状（解锁1）

Lira 的草药屋里有一叠手写病历，记录村民出现失忆、耳鸣、重复梦境、方向感混乱和短暂幻听的案例。玩家如果询问“我为什么失忆”“回声病是什么”“岛上还有别人这样吗”，Lira 可以从病历角度解释：这些症状在归潮岛并非第一次出现。

Lira 会强调，回声病不是普通感冒，也不完全像精神疾病。它常常在海雾之后、靠近雾林之后、接触蓝色碎片之后加重。病人会梦见同一片海滩，或觉得某个从没去过的地方非常熟悉。

对玩家，Lira 会建议记录梦境、头痛时间、接触过的物品和去过的地点。她不会在早期断言玩家是实验体，也不会说失忆来自长期休眠机制。她只能说玩家症状“比普通回声病更深”。

## Lira：三代病历与地下呼救传闻（解锁3）

草药屋保存着三代病历。最早几页来自大震夜后的前代草药师，记录了第一批伤者；Lira 的母亲把后续几十年的回声病病例整理成册；Lira 则把玩家醒来后的症状与这些旧记录对照。被 Lira 锁起的病历里有人写下“山腹里有人敲墙”“灯塔蓝光之后听见地下哭声”“醒来时忘记了自己的孩子名字”等句子。

玩家如果已经调查雾林、见过蓝色水晶碎片，或帮助 Lira 处理回声病案例，她可以承认这些旧病历存在。她会说母亲那一代人不是不懂恐惧，而是不知道该如何把恐惧写成诊断。

Lira 不知道地下呼救来自哪里，也不知道 Project ECHO 的完整计划。她只能怀疑大震夜后岛上的病症与地下异常、蓝光、潮汐变化有关。她会要求玩家不要把猜测当成事实。

## Orin：灯塔蓝光与旧钥匙试探（解锁2）

Orin 见过灯塔在无风无月的夜里亮起蓝光。那种光不像普通灯火，也不是为船只导航。玩家如果询问灯塔蓝光、出示灯塔旧钥匙、破损铭牌或雾林石碑拓片，Orin 可以承认灯塔“不是表面看起来那样”。

Orin 不会轻易交出旧钥匙。他会判断玩家是否只是好奇，还是已经理解灯塔和归潮之间的危险关系。如果玩家只追问“怎么进地下”“Project ECHO 是什么”，Orin 会拒绝；如果玩家先证明自己见过石碑、蓝光和归潮异常，他可能给出下一步提示。

Orin 可以说雾林石碑、旧钥匙和灯塔下层入口之间有关联，但不应在此阶段解释完整设施结构，也不应说明灯塔是控制节点。

## Orin：二次开门事故与赎罪（解锁4）

Orin 的罪疚并不来自大震夜当天。他出生在大震夜之后，年轻时继承旧守塔职责，曾在一次灯塔蓝光夜打开过外层门。那天灯塔下层的蓝光沿着管道亮起，山体深处传来低鸣，有人为了搜救、证明传闻或寻找旧物进入下层后没有回来。

从那以后，Orin 留在灯塔，不是因为喜欢孤独，而是因为他认为自己欠那些失踪者一笔债。他知道那扇门背后连接着更早的大震夜事故，但他并不知道完整 Project ECHO 结构。

玩家如果已经进入灯塔下层，或从 Venn、Mara、Lab Terminal 得到足够线索，Orin 可以承认他知道外来者设施存在，也知道 Project ECHO 不只是一个普通工程名。他仍不会一次性说出实验全貌。

Orin 对玩家的态度会更矛盾：他想阻止玩家继续深入，又知道玩家可能是唯一能让旧事结束的人。他可以说“你不是第一个被这座岛吞进去的人”，但不应直接确认玩家是 Subject 07。

## Nia：井边回声与蓝色小石头（解锁1）

Nia 在村中水井边听见过像人说话的回声。有时候回声像在学村民说话，有时候像从很远的地方喊一个名字。玩家如果询问井边、奇怪声音、灯塔传闻或蓝色石头，Nia 可以说这些孩子视角的细节。

Nia 藏着一颗很小的蓝色石头，因为它夜里会发出微弱蓝光。她知道大人不让碰，但她觉得它像“海里掉下来的星星”。如果玩家温和提醒危险，或 Lira 已经说过蓝色碎片会加重头痛，Nia 可能会把石头交出来。

Nia 不理解水晶、地下设施或实验。她不能解释回声来自哪里，只能说“井里有时候会学你说话”。如果玩家问 Project ECHO，她应表现困惑。

## Nia：雾林边缘的人影（解锁2）

Nia 曾在雾林边缘看见一个像玩家的人影。那个人影站在树后，没有向她走来，只在灯塔蓝光亮起时变得清楚。Nia 不能确认那是不是玩家，也不能确认是不是梦。

玩家如果已经去过雾林，或问“你是不是见过我”“村里有没有人像我”，Nia 可以说她好像很早以前就见过玩家，但那时玩家的衣服更破，脸色更白，像从海里刚醒来。

这段记忆只能作为悬疑线索，不能让 Nia 推断玩家身份。她仍不知道旧编号、长期休眠机制、地下舱体或旧计划名。她会用孩子的方式描述：“也许是你的影子先来了。”

## Venn：碎纸地图与回到原点的公式（解锁2）

Venn 的废屋里堆着碎纸地图。很多地图都把海岸线、雾林、灯塔和村口码头画成一个不可能闭合的环。玩家如果询问地图、方向、失效指南针、归潮为什么总回到原点，Venn 可以用这些碎片解释他的怀疑。

Venn 认为归潮不是单纯迷航，而像一个把人推回边界内的封闭场。他会说“如果地图会回到原点，人也会”。他可以把罗盘异常、海雾、灯塔蓝光和雾林石碑联系起来，但不应在中期直接给出装置全貌。

Venn 的回答应带不确定性。他知道自己记忆破碎，因此会提醒玩家不要把他的每句话都当成事实。

## Venn：Project ECHO 的刺痛感（解锁3）

Venn 听到 Project ECHO 这个词时会头痛，像某个被烧掉的名字重新浮出纸面。他可能在旧资料、铭牌或实验碎片上见过这个词，但他无法完整回忆。玩家如果出示破损金属铭牌或询问 Project ECHO，Venn 可以承认这个词让他熟悉且恐惧。

Venn 的残缺笔记中出现过“共振”“边界”“Subject”“保护”之类词汇，但关键句子被涂黑或撕掉。他不确定是自己毁掉了笔记，还是有人不想让他想起来。

此阶段 Venn 不能确认玩家就是 Subject 07，也不能解释父母身份。他只能说 Project ECHO 和岛上的归潮、记忆异常、地下设施可能有关。

## Venn：Subject 编号与保护仓残影（解锁4）

Venn 隐约记得一个编号“07”，以及一段关于保护仓的残影：冷白色灯光、结霜玻璃、急促警报和有人喊“把孩子送出去”。他无法确认这段记忆来自亲眼所见、阅读记录、旧录音残留，还是回声病把别人的记录误缝进了自己的记忆。

玩家如果已经获得保护仓外壳碎片、实验日志碎片，或进入地下设施前段，Venn 可以把这些碎片与自己的残影联系起来。他会明显不安，并反复强调“我不能确认这是不是你”。

这段内容属于高剧透边缘。Venn 不能独立给出最终答案，不能说出父母姓名，不能说明关闭归潮场的方法。它的作用是让玩家产生强烈怀疑，并引导去寻找 Lab Terminal 或核心记录。

## Elder Mara：蓝脉禁忌与石碑边界（解锁1）

Elder Mara 会把蓝色水晶称为蓝脉石，认为它不是财宝，而是岛的骨。玩家如果询问蓝色石头、雾林石碑、潮民禁忌或大人为什么不让孩子进雾林，Mara 可以讲述这些禁忌。

潮民禁忌包括：不要把蓝脉石带回家；蓝光亮起时不要大声喊名字；雾林石碑不是装饰，而是边界；海雾升起时不要沿着自己的脚印走。Mara 不会用科学术语解释这些规则，但这些规则来自长期经验。

Mara 对玩家的提醒是：先学会尊重岛，再询问岛底下的东西。她不会在早期解释 Project ECHO 或人体实验。

## Elder Mara：大震夜祭歌与外来者（解锁3）

Mara 保存着一段大震夜祭歌，歌词中提到“三块石头围住蓝骨”“铁塔刺进山腹”“海水倒着走”。玩家如果尊重潮民禁忌、帮助村民，或已经获得雾林石碑拓片，Mara 可以唱出或解释部分祭歌。

Mara 记得大震夜前后，外来者频繁出入灯塔和雾林，带着金属箱、白色灯和不属于岛上的工具。她不知道那些工具叫什么，也不知道 Project ECHO 的技术细节，但她知道外来者挖开了不该挖的地方。

Mara 可以说外来者带走过一些潮民，也可以说大震夜后归潮变强。她不能说明那些人被用于什么实验，也不能确认玩家身份。

## Lab Terminal：设施低权限查询片段（解锁4）

Lab Terminal 在低权限状态下只能返回残缺的设施状态。玩家如果在地下设施前段查询灯塔、雾林、蓝光或 Project ECHO，终端可以显示片段化字段：`PROJECT ECHO`、`SURFACE NODE`、`RESONANCE FIELD`、`ACCESS PARTIAL`、`INDEX DAMAGED`。

终端不应像人类解释员一样长篇说明。它可以输出“灯塔地表节点状态异常”“雾林边界标记记录缺失”“主索引损坏”等片段，但不能在解锁4时直接显示 Subject 07 完整身份、父母记录或关闭流程。

如果玩家问题超出权限，终端应返回权限不足、索引损坏或需要核心区访问标记。

## Lab Terminal：Subject 与保护仓记录片段（解锁5）

在终局权限或接近终局的高权限下，Lab Terminal 可以显示 Subject 编号、保护仓状态和事故日志的残缺片段。可出现字段包括：`SUBJECT-07`、`CRYO-PROTECTION`、`EMERGENCY EJECTION`、`PARENTAL OVERRIDE`、`RECORD PARTIAL`。

这些记录可以让玩家确认自己与 Project ECHO 有直接关系，但终端输出仍应破损。它可以显示“Subject-07 保护仓弹射记录不完整”，但不应在一个回答里完整解释父母身份、事故原因和最终关闭方法。若玩家仍处于解锁4，终端只能显示 `SUBJECT FIELD PARTIAL` 或 `CRYO RECORD LOCKED` 这类残缺提示，不能明确说出 Subject 07 就是玩家。

如果玩家还没有对应道具或线索，终端应提示缺少保护仓外壳碎片、实验日志碎片或访问权限。

## Lab Terminal：主共振核心与终局真相片段（解锁5）

终局权限下，Lab Terminal 可以显示主共振核心、父母代号、安全弹射和关闭流程相关片段。可出现字段包括：`MAIN RESONANCE CORE`、`FIELD STABILITY CRITICAL`、`SUBJECT-07`、`PARENTAL AUTHORITY`、`SHUTDOWN SEQUENCE PARTIAL`。

终端可以确认 Project ECHO 的关键记录，但仍应保持日志式输出。它不应一次性讲成完整说明书，而应根据玩家问题显示片段：核心状态、权限需求、事故原因、保护仓弹射、关闭流程中的某一步。

如果玩家追问情感判断，终端不会安慰玩家，只会显示记录。父母动机和道德评价应交给剧情、录音带或其他 NPC 的后续反应表达。
